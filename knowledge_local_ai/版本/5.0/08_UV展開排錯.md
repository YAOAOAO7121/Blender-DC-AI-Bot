## UV 要怎麼展開（Unwrap）
在 Edit Mode 選要展開的面，按 U 選展開方式。5.0 文件列出 Angle Based、Conformal 與 Minimum Stretch；會覆寫選取面的既有 UV。Minimum Stretch 目標是減少面積與角度的扭曲。

## UV 拉伸或島黏在一起怎麼查（Margin / Correct Aspect）
Correct Aspect 要考慮材質對應的影像比例；此版本文件要求材質含 Image Texture，並在 Shader Editor 選取該節點。Margin 控制島間空隙。
