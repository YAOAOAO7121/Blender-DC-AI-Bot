## 網格建模從哪裡開始（Mesh Modeling）
可以先建立圓形、立方體或圓柱等基本網格，再逐步編輯成較複雜的形狀。

## 物件、編輯與雕塑模式有何不同（Object / Edit / Sculpt Mode）
Object Mode 用於物件建立、合併等物件層級操作。Edit Mode 處理多數網格編輯。Sculpt Mode 使用筆刷雕塑形狀。
