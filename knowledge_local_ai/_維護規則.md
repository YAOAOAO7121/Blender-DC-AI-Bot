# 來源、去重與更新規則

## 範圍
產品 Blender；教學筆記繁體中文、原始官方文件英文；正式整理範圍 4.2 與 5.0。其他版本待確認，不把 5.x 當作一個確定版本。
「通用」只表示已核對 4.2 與 5.0 的這些概念相同，不表示對所有版本成立。

## 來源與授權
優先官方版本文件、官方 release notes、官方維護庫；其次為學術機構及可信維護者。AI 筆記不是權威來源。
每筆記錄原 URL、實際 URL、維護者、版本、語言、擷取時間（UTC+08:00）、本地路徑、SHA-256、授權與授權證據 URL。
本次原文為官方版本分支的 RST 快照，不含圖片、下載包或完整手冊；分支會變動，以擷取日期及雜湊識別當次內容。
Blender Documentation Team 的手冊文字依各版本 copyright.rst 授權 CC-BY-SA 4.0 或後續版本，須署名、附來源與授權連結，改寫/翻譯須註明並同樣授權。此處不推定標誌、商標、圖示、程式碼、Python 腳本也適用此授權。既有課程筆記授權未知，不自動套用 CC。

## 去重
先比原始位元組 SHA-256；再將段落空白正規化比雜湊。相似但不相同的段落只列人工審核，不自動刪除。
同一 URL/版本/語言只設一個來源 ID。不同版本即使內容相同，也保留各自來源記錄；通用摘述引用兩者，避免失去版本證據。
新舊快照先比對再審核，不自動覆寫已發布筆記。若移除重複筆記，保留舊路徑到新文件 ID 的對照。

## 更新
每月人工檢查一次官方來源；課程改版或來源修訂時額外檢查。這是維護政策，尚未設定自動排程。
重抓相同 URL 到暫存區→驗證 HTTP 狀態及格式→比對 SHA-256→有變更才產生差異→教師核對操作→更新摘述與來源紀錄。
下載失敗保留舊版並記錯誤，不拿錯誤頁替換原文。授權改變則先停止新內容匯入，保留舊授權證據。
每次更新保留 previous_sha256、checked_at、reviewer、reviewed_at、status、變更原因與課程實測版本。

## 本擴充版檢索規則
knowledge.py 預設讀 knowledge_local_ai，僅納入含 kb JSON 且狀態為 source_checked 或 approved 的文件。
共同概念放通用知識；操作差異放版本/4.2 或版本/5.0；待審核、官方原文、網路整理及底線目錄不載入。
明確指定版本時只搜尋共同概念與該版；未指定時讀 KB_VERSION，未設定則只搜共同概念。
輸入明確不支援版本時不拿另一版充數；比較兩版本的問題可分別檢索並附版本標籤。
一秒內沿用記憶體索引；更新後最多一秒重掃，沒有修改的文件沿用磁碟解析快取。關鍵字倒排索引先選候選段落再算 BM25。
category_of 支援巢狀路徑，分類優先用 kb.topic。文件及段落完全重複時只在同版本範圍、同主題合併，保留來源 URL。
原 bot.py 的網路筆記流程仍存在，但新寫入舊 knowledge/網路整理 的文件不會自動變成已核可教材；應補來源、版本、授權及 kb 中繼資料，審核後移入新知識庫。
KB_ALLOW_LEGACY 預設關閉；不要靠開啟它來宣稱舊筆記已審核。
