# 修改器（編修器 Modifiers）
<!-- 適用 Blender 4.x / 5.x。小樽老師的文章把 Modifier 稱為「編修器」 -->

## 修改器是什麼、怎麼加（Add Modifier、編修器）
修改器是「不破壞原始網格」的自動效果，可以隨時調整或關掉。
加法：選取物件 › 右側 Properties 的藍色扳手圖示（Modifier Properties）› Add Modifier，分成 Edit、Generate、Deform、Physics 等類別。
- 每個修改器右上角有顯示開關：螢幕圖示（視窗顯示）、相機圖示（渲染時顯示）
- Ctrl + A（滑鼠放在修改器上）或下拉選單 › Apply：套用，把效果變成真正的網格
- 加修改器前，建議先套用縮放（Ctrl + A › Scale），否則效果容易不均勻

## 修改器的順序（Modifier Stack）
修改器由上往下依序計算，順序不同結果就不同。例如：
- Mirror 在 Subdivision Surface 上面：先鏡像再一起細分，中間接縫平滑（通常是對的）
- Bevel 在 Subdivision 上面：先倒角再細分，邊緣比較銳利
拖曳修改器標題左側的點點，或下拉選單 Move to First / Last 可以調整順序。

## 細分曲面（Subdivision Surface，Ctrl + 1～5）
讓模型變得圓滑。物件模式選取物件按 Ctrl + 1、Ctrl + 2… 可以直接加上並設定細分等級。
- Levels Viewport：視窗中的細分等級；Render：渲染時的等級
- 想保留某些邊銳利：在那條邊旁邊加切線（支撐線 Holding Edge），或用 Shift + E 摺痕
- 方塊細分變成一顆球是正常的，因為邊太少；加支撐線才會變成圓角方塊
- 等級越高面數爆增（每升一級約 ×4），通常視窗 1～2、渲染 2～3 就夠

## 鏡像（Mirror，對稱建模）
做對稱的東西（人、車、杯子）時，只要做一半，另一半自動長出來。
1. 編輯模式刪掉一半（例如 X 軸負的那一半）
2. 加 Mirror 修改器，Axis 選 X
3. 勾選 Clipping：中間的點不會穿過鏡像面，避免中間裂開
4. 勾選 Merge：中間的點自動合併
注意：鏡像是以「物件原點」為中心，原點不在中間的話鏡像會跑掉。Bisect 可以自動切掉越過中線的部分。

## 陣列（Array，重複排列）
把物件重複排列成一排，例如樓梯、欄杆、鏈條。
- Count：數量；Fit Type 可以改成 Fit Length（固定長度）或 Fit Curve（沿曲線）
- Relative Offset：以物件尺寸為單位的間距（1 = 剛好接在一起）
- Constant Offset：固定距離間隔
- Object Offset：用一個空物件（Empty）控制，旋轉 Empty 可以做出環狀排列（例如時鐘刻度）
- 搭配 Curve 修改器可以讓陣列沿曲線彎曲
5.0 另外新增了用幾何節點做的 Array 修改器，舊的 Array 仍然可以用。

## 加厚（Solidify）
讓沒有厚度的面（例如平面、衣服、杯子的薄壁）長出厚度。
- Thickness：厚度，負值往內、正值往外
- Even Thickness：讓厚度更平均
- 厚度不平均或變形時，先套用縮放

## 倒角修改器（Bevel Modifier）
和編輯模式的 Ctrl + B 一樣把邊變圓角，但可以隨時調整。
- Amount：倒角大小；Segments：段數，越多越圓
- Limit Method › Angle：只倒角夾角大於設定角度的邊（最常用）
- Weight：只倒角你在編輯模式設定過倒角權重的邊
- Shading › Harden Normals：讓倒角的著色更乾淨（產品建模常用）
- 倒角大小兩邊不一樣、怪怪的：先套用縮放

## 布林運算（Boolean，聯集、交集、差集）
讓兩個物件做聯集、交集、差集，例如在牆上挖窗戶。
用法：選取要被運算的物件（例如方塊）› Add Modifier › Generate › Boolean › 選擇運算方式 › Object 選擇「拿來運算的物件」（例如球）。
- Union（聯集）：兩者合併成一個，重疊的內部移除
- Intersect（交集）：只留下兩者重疊的部分
- Difference（差集）：用運算物件把自己挖掉（最常用）
- Solver：Exact（準確，預設）比較慢但不容易出錯；Fast（快速）速度快但容易破面；4.5 以後另有 Manifold 選項，速度快且穩定，但兩個物件都需要是封閉的網格
- 運算物件做完不會消失，移開或隱藏它（H）才看得到結果；按 Apply 套用後，就可以把運算物件刪掉
- 運算物件常設成 Object Properties › Viewport Display › Display As › Wire，方便看
布林失敗常見原因：網格沒有封閉（有破洞）、法線反了、兩個面剛好完全重疊、縮放沒套用。

## 旋轉成形修改器（Screw，做杯子、瓶子、螺絲）
畫好半邊剖面線條後加 Screw 修改器，會繞軸旋轉長出完整的形狀。
- Angle：旋轉角度；Steps：段數
- Screw：每圈往上移動的距離，可以做螺旋、彈簧
- 勾選 Merge 讓接縫處合併；形狀變黑可以勾 Flip 翻轉法線

## 簡單變形（Simple Deform，扭轉、彎曲、錐形）
- Twist：扭轉（做麻花、螺旋柱）
- Bend：彎曲
- Taper：一端變細
- Stretch：拉伸
模型需要有足夠的切線才彎得順。旋轉軸方向不對時，可以設定 Origin 用一個空物件控制。

## 沿曲線彎曲（Curve Modifier）
讓物件沿著一條曲線變形，例如做水管、蛇、文字繞圈。
1. 新增一條曲線（Shift + A › Curve）
2. 物件加 Curve 修改器 › Curve Object 選那條曲線
3. Deformation Axis 設定物件沿哪個軸彎
常搭配 Array 修改器（Fit Type 設 Fit Curve）讓物件沿曲線重複排列。

## 晶格變形（Lattice）
用一個籠子（Shift + A › Lattice）包住物件，物件加 Lattice 修改器，進入籠子的編輯模式移動控制點，可以整體捏塑物件外型。適合做卡通變形、調整整體比例。

## 減面（Decimate）
自動減少面數，常用在 AI 生成模型、掃描模型太重的時候。
- Collapse：Ratio 設 0.5 就是減少一半面數
- Un-Subdivide：反細分，適合規則的網格
- Planar：合併平坦區域的面
減面後佈線會變亂（大多是三角面），不適合再拿來細分或做動畫。

## 合併重複點（Weld）
修改器版的「M › By Distance」，自動合併距離很近的點，不破壞原始網格。

## 包覆貼合（Shrinkwrap）
讓物件貼合到另一個物件表面，常用在衣服貼身、重新拓樸、讓貼紙貼在曲面上。Offset 可以設定離表面的距離。

## 置換（Displace，用貼圖做凹凸）
用黑白貼圖或程序紋理推動網格的點，做地形、岩石表面。網格需要夠多的面才看得出細節（先 Subdivide 或加 Subdivision Surface）。

## 重新網格化（Remesh）
把整個模型重新生成平均的網格。Voxel 模式最常用，Voxel Size 越小越細緻。適合雕刻前整理、AI 模型重建網格。會失去 UV。

## 線框（Wireframe）
把模型的邊變成實體的線框結構，可以做出鐵網、建築結構的造型效果。

## 修改器套用後可以復原嗎
套用（Apply）之後效果就變成真正的網格，修改器消失。想反悔只能 Ctrl + Z。
建議：套用前先 Shift + D 複製一份備份、或另存新檔；不需要的時候可以先不套用，渲染和匯出時多數格式可以選擇自動套用修改器。
