# 動畫基礎（關鍵影格、曲線編輯器、動作原理）
<!-- 對應課程第 8 週。適用 Blender 4.x / 5.x -->

## 關鍵影格是什麼（Keyframe）
關鍵影格是「某一格時，物件在哪裡、轉多少、多大」的紀錄。設定兩個關鍵影格，Blender 會自動補出中間的動作（補間 In-between）。
例如：第 1 格球在左邊、第 48 格球在右邊 → 播放時球會從左滑到右。

## 怎麼打關鍵影格（I、Insert Keyframe）
1. 在時間軸（Timeline）移到要的格數
2. 擺好物件的位置、旋轉、縮放
3. 滑鼠在 3D 視窗按 I：插入關鍵影格（4.1 以後預設直接記錄位置、旋轉、縮放，不跳選單；要選擇記錄哪些屬性按 K）
4. 換一格、改變物件、再按 I
也可以把滑鼠移到任何數值欄位上（例如 N 面板的 Location、材質顏色、燈光強度）按 I，只為那個數值打關鍵影格，欄位會變成黃色（有關鍵影格的格）或綠色（有動畫但不在關鍵影格上）。
- Alt + I：刪除目前這格的關鍵影格
- 數值欄位上按右鍵 › Clear Keyframes：清除該數值所有關鍵影格

## 自動記錄關鍵影格（Auto Keying）
時間軸上的圓點按鈕（Auto Keying）開啟後，只要移動、旋轉物件就會自動打關鍵影格。
很方便但也很容易不小心打到不想要的格，用完記得關掉。

## 時間軸和播放（Timeline、Space）
- Space：播放／暫停（播放中按 Esc 停止並回到原本格數）
- Shift + Left：跳到開始格；Shift + Right：跳到結束格
- Left / Right 方向鍵：前後一格
- Up / Down 方向鍵：跳到下一個／上一個關鍵影格
- 時間軸右邊的 Start、End：動畫範圍
- Ctrl + 滾輪 或 Alt + 滾輪：在 3D 視窗中逐格前後移動
- 播放很卡：可以降低細分等級、隱藏重物件、或用 View › Viewport Render Animation 先輸出預覽

## 移動、複製、縮放關鍵影格（Dope Sheet）
上方切到 Animation 工作區，或把區域切換成 Dope Sheet（攝影表），可以看到所有關鍵影格（菱形點）：
- 點選或框選關鍵影格，G 移動、S 縮放（以播放頭為中心，可以整段加速或放慢）
- Shift + D：複製關鍵影格
- X：刪除
- Ctrl + C / Ctrl + V：複製貼上關鍵影格（Ctrl + Shift + V 鏡像貼上，做對稱的動作）
時間軸（Timeline）上也可以直接拖曳關鍵影格。

## 曲線編輯器（Graph Editor、F-Curve）
Graph Editor 把每個屬性的變化畫成曲線：橫軸是時間、縱軸是數值，曲線的斜率就是速度。
- 坡度陡：變化快；平：慢；水平：停住
- 選取點後 G 移動、R 旋轉把手、S 縮放
- Home：顯示全部曲線；左側清單點選要看的屬性（例如 X Location）
- Ctrl + Tab（或 Tab）可以和 Dope Sheet 切換
- 曲線上的控制把手決定加速減速的形狀

## 補間方式：等速、緩入緩出、跳格（Interpolation、T）
在 Graph Editor 或 Dope Sheet 選取關鍵影格按 T：
- Bezier（預設）：緩入緩出，動作開始慢、中間快、結束慢
- Linear：等速，適合機械運轉、一直旋轉的東西
- Constant：沒有過渡，直接跳到下一個值（定格動畫、閃爍效果）
- Easing 類型（Sine、Quad、Back、Bounce、Elastic）：內建的特殊曲線，Bounce 可以做彈跳、Elastic 做彈簧
按 Ctrl + E 選擇 Ease In / Ease Out。
把手類型按 V：Auto Clamped（預設、不超出）、Vector（尖角）、Aligned、Free。

## 無限循環、一直旋轉（Cycles 修改器、Extrapolation）
例如風扇一直轉、走路循環：
- Graph Editor 選取曲線 › Channel › Extrapolation Mode（Shift + E）› Linear Extrapolation：照最後的速度一直延續（一直旋轉）
- Make Cyclic：重複整段動畫（循環動作）
- 或在 N 面板 › Modifiers › Add Modifier › Cycles

## 動畫十二法則（動作原理 12 Principles of Animation）
迪士尼動畫師歸納的動畫原則：
1. 擠壓與伸展（Squash & Stretch）：落地時壓扁、彈起時拉長，體積不變
2. 預備動作（Anticipation）：跳之前先蹲、丟之前先往後拉
3. 演出布局（Staging）：讓觀眾一眼看懂重點
4. 連續動作與關鍵姿勢（Straight Ahead & Pose to Pose）：逐格畫 vs 先定關鍵姿勢再補中間
5. 跟隨與重疊動作（Follow Through & Overlapping）：停下來後頭髮、衣服、尾巴還會繼續晃
6. 緩入緩出（Slow In & Slow Out）：起步和停止慢、中間快（Bezier 曲線）
7. 弧形軌跡（Arcs）：自然動作多半走弧線
8. 次要動作（Secondary Action）：走路時手擺動、表情變化
9. 時間節奏（Timing）：格數越少動作越快、越輕
10. 誇張（Exaggeration）：放大動作讓它更有趣、更清楚
11. 立體造型（Solid Drawing）：姿勢要有重量、體積感
12. 吸引力（Appeal）：角色和動作要有魅力

## 彈跳球練習（Bouncing Ball）
動畫入門經典練習：
1. 在最高點和落地點打 Z 位置的關鍵影格（例如 1、12、24 格：高、地、高）
2. Graph Editor 中：落地的點把手改成 Vector（V），讓碰地瞬間是尖角（速度最快、瞬間反彈）；最高點保持平滑（速度最慢）
3. 加上擠壓伸展：落地那格 Z 縮放壓扁、X Y 變寬；空中下落時稍微拉長
4. 每次彈跳越來越低、越來越短，表現能量損失
5. X 方向用 Linear 等速前進

## 動作路徑、洋蔥皮（Motion Paths、Onion Skin）
- Object Properties › Motion Paths › Calculate：在畫面中顯示物件的移動軌跡，方便檢查弧線
- 骨架在 Pose 模式也有 Motion Paths
- Grease Pencil 2D 動畫有洋蔥皮（Onion Skinning）可以看前後幾格

## 讓材質、燈光、任何數值動起來
幾乎所有數值都可以打關鍵影格：滑鼠移到欄位上按 I。
例如：材質 Emission Strength 0 → 10 做燈亮起、燈光顏色變化、修改器的數值（Array 數量、Bevel 大小）、攝影機焦距。

## 形狀鍵、表情動畫（Shape Keys）
形狀鍵記錄同一個網格的不同形狀，可以在形狀之間平滑變化，常用在表情（眨眼、張嘴）。
1. Object Data Properties › Shape Keys › 按 + 新增 Basis（原始形狀）
2. 再按 + 新增一個 Key 1，進入編輯模式修改形狀（例如閉眼）
3. 回到物件模式，調整 Key 1 的 Value（0～1），在 Value 上按 I 打關鍵影格
修改形狀時要先選到正確的 Shape Key，否則會改到 Basis。

## 動畫圖層、重複使用動作（NLA Editor、Action）
每段動畫存成一個 Action（動作）。NLA Editor 可以把 Action 變成片段（Push Down），像剪輯一樣排列、重複、混合多段動作（例如走路接跑步）。
進階功能，初學先用 Dope Sheet 和 Graph Editor 即可。

## 父子關係跟著動（Parent、Ctrl + P）
讓一個物件跟著另一個動：先選子物件，再選父物件（最後選的），Ctrl + P › Object。
父物件移動、旋轉時子物件會跟著；子物件仍然可以自己動。
Alt + P › Clear Parent（Clear and Keep Transformation 保持目前位置）。
常用：輪子跟著車身、攝影機跟著空物件。
