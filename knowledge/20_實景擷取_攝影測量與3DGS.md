# 實景擷取：攝影測量與 3D 高斯潑濺（Photogrammetry、3DGS）
<!-- 對應課程第 12～13 週。工具名稱僅供參考，以老師課堂介紹為準 -->

## 攝影測量是什麼（Photogrammetry）
用大量不同角度的照片，讓電腦計算出物體的 3D 形狀和貼圖。
原理：軟體找出照片之間相同的特徵點 → 推算每張照片的拍攝位置（Structure from Motion，SfM）→ 產生點雲 → 重建網格 → 把照片投影成貼圖。
輸出是一般的網格模型（OBJ、FBX、GLB），可以直接在 Blender 編輯、打光、渲染。
常見工具：RealityScan（前身 RealityCapture）、Meshroom（開源免費）、Agisoft Metashape、手機 App 如 Polycam、KIRI Engine、Scaniverse。

## 3D 高斯潑濺是什麼（3D Gaussian Splatting、3DGS）
3DGS 也是用很多照片或影片重建場景，但結果不是網格，而是幾十萬到幾百萬個「半透明、有顏色的模糊橢圓點（高斯）」疊在一起。
優點：
- 畫面非常寫實，連反光、樹葉、毛髮、半透明等攝影測量很難處理的東西都能呈現
- 可以即時瀏覽
缺點：
- 不是網格，不能直接用 Blender 的建模工具修改、不容易重新打光
- 檔案大（.ply 或 .splat、.spz 等格式）
- 物件表面不是真正的實體，碰撞、物理模擬需要另外處理
常見工具：Postshot、Polycam、Luma、Scaniverse、KIRI Engine，以及開源的 nerfstudio / gsplat 等。

## 攝影測量和 3DGS 怎麼選
- 需要可以編輯、打光、3D 列印、做遊戲的模型 → 攝影測量（網格）
- 需要寫實的場景當背景、展示、虛擬導覽 → 3DGS
- 反光、透明、細碎（樹葉、頭髮）的東西 → 3DGS 表現比較好
- 想要兩者兼得：部分工具可以從 3DGS 轉出網格，但品質通常不如直接攝影測量

## 拍攝技巧（照片重疊、光線、拍攝路徑）
- 重疊率：相鄰兩張照片要有約 60～80% 的畫面重疊
- 繞著物體走，而不是站在原地轉身拍；拍 2～3 圈不同高度（低、平、高）
- 物件約 50～200 張，場景可能需要數百張；用影片的話慢慢移動，再每秒取 2～3 張
- 光線平均：陰天或室內柔光最好，避免強烈陰影和直射陽光；光線不要在拍攝中途改變
- 對焦清楚、避免晃動模糊；手機可以鎖定曝光和對焦
- 不適合的物體：鏡子、玻璃、亮面金屬、純白無紋理的牆（找不到特徵點）
- 拍攝時物體不能移動（人、樹被風吹、路過的行人都會造成殘影）

## 掃描結果匯入 Blender（攝影測量模型）
1. 從軟體匯出 OBJ、FBX 或 GLB（含貼圖）
2. File › Import 匯入
3. 校正：方向（旋轉到地面水平）、尺寸（用一個已知長度的東西對照，S 縮放到正確大小並套用）
4. 清理：刪除背景雜點和地面多餘的部分（編輯模式框選刪除，L 選取相連）、補破洞
5. 減面：掃描模型通常很重，用 Decimate 修改器

## 3DGS 匯入 Blender
Blender 本身沒有內建 3DGS 顯示，需要安裝外掛（例如 KIRI Engine 提供的 3DGS Render 外掛，或其他社群外掛）匯入 .ply：
- 4.2 以後可以在 Edit › Preferences › Get Extensions 搜尋，或到外掛官網下載安裝
- 3DGS 在 Blender 中通常要用 Eevee 顯示，效能需求高，點太多時會很卡
- 可以先在原本的軟體裁切掉不需要的範圍、減少點數再匯入
外掛和版本更新很快，使用時以老師課堂說明和外掛的說明為準。

## 把 3D 物件放進實景場景（三路徑整合、鏡頭匹配與光線一致性）
把自己做的模型或 AI 生成的模型放進掃描場景時，要讓它們看起來屬於同一個空間：
- 比例：場景和物件都校正成真實尺寸
- 地面接觸：物件要確實貼地，加上接觸陰影（Shadow Catcher 或 AO）
- 光線方向：觀察場景中陰影的方向，用 Sun 燈或 Area 燈從相同方向打光
- 光線顏色與亮度：可以在現場拍一張 360 度全景（HDRI）當環境光，或用場景本身的顏色取樣
- 攝影機：焦距、高度與場景拍攝時相近；需要鏡頭移動時讓攝影機在場景中移動
- 色調：渲染後在合成器統一調色、加一點雜訊與景深，讓 CG 和實景融合

## 陰影接收（Shadow Catcher，物件影子落在實景上）
在實景照片或影片上放 3D 物件時，讓陰影落在「看不見的地面」上：
1. 新增一個平面當地面，放在物件下方
2. 選取平面 › Object Properties › Visibility › 勾選 Shadow Catcher（Cycles）
3. Render Properties › Film › 勾選 Transparent
4. 渲染後在合成器用 Alpha Over 疊在背景照片上
這個平面只會留下陰影和反射，自己本身是透明的。

## 實拍影片加 3D 物件（Camera Tracking、攝影機追蹤）
Blender 內建攝影機追蹤（Movie Clip Editor）：從手持拍攝的影片計算攝影機的移動，讓 3D 物件黏在畫面中：
1. 切到 Motion Tracking 工作區，開啟影片
2. 設定攝影機焦距、感光元件尺寸
3. 追蹤特徵點（至少 8 個以上、分布平均），Ctrl + T 追蹤
4. Solve Camera Motion 計算攝影機（Solve Error 越接近 0 越好，小於 0.5 不錯）
5. Setup Tracking Scene 自動建立攝影機與場景
這是進階技巧，需要影片清晰、有足夠的特徵點。
