# 介面與視角操作

## 旋轉、平移、縮放視角（滑鼠中鍵）
- 旋轉視角：按住滑鼠中鍵拖曳
- 平移視角：Shift + 中鍵拖曳
- 拉近拉遠：滾動滾輪（或 Ctrl + 中鍵拖曳）
- 也可以用畫面右上角的導航小工具：拖曳座標軸球旋轉、拖曳手掌平移、拖曳放大鏡縮放

## 筆電沒有中鍵或沒有數字鍵盤
到 Edit › Preferences › Input：
- 勾選 Emulate 3 Button Mouse：之後可以用 Alt + 左鍵 代替中鍵
- 勾選 Emulate Numpad：鍵盤上方的數字鍵就能當數字鍵盤用
也可以按 `~`（Esc 下面那顆）叫出視角圓盤選單，用滑鼠選前、後、上、左右視角。

## 切換正視圖、側視圖、上視圖（數字鍵盤）
- Numpad 1：前視圖；Ctrl + Numpad 1：後視圖
- Numpad 3：右視圖；Ctrl + Numpad 3：左視圖
- Numpad 7：上視圖；Ctrl + Numpad 7：下視圖
- Numpad 5：切換透視／正交
- Numpad 0：從攝影機看出去

## 物件找不到、視角跑掉了
- 選取物件後按 Numpad .（數字鍵盤的小數點）：視角對準選取的物件（選單 View › Frame Selected）
- Home：讓畫面顯示全部物件（View › Frame All）
- Shift + C：3D 游標回到原點並顯示全部物件
- 如果只看得到一個物件、其他都不見了，可能是誤按 Numpad / 進入「區域視圖」，再按一次 Numpad / 就能退出

## 常用面板
- N：開關右側側邊欄（物件的位置、旋轉、縮放數值都在 Item 分頁）
- T：開關左側工具列
- F3：搜尋功能，忘記指令在哪裡時直接打英文名稱搜尋
- Ctrl + Space：把滑鼠所在的區域放到最大，再按一次還原
