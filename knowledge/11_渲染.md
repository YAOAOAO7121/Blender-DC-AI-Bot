# 渲染（算繪 Render）
<!-- 對應課程「算繪輸出」。適用 Blender 4.x / 5.x；4.2 以後的 Eevee 是新版（Eevee Next） -->

## Eevee 和 Cycles 差在哪（渲染引擎 Render Engine）
Render Properties（背面相機圖示）› Render Engine：
- Eevee：即時渲染，速度快（幾秒一張），適合動畫、風格化、快速預覽；反射、折射、間接光是近似計算
- Cycles：光線追蹤（路徑追蹤），光影真實但比較慢，適合寫實、產品、玻璃、室內
- Workbench：只顯示實體與顏色，適合快速檢查模型、技術圖
建議：先用 Eevee 或 Material Preview 調整，最後需要真實光影再用 Cycles。兩者的材質大部分通用，但看起來不會完全一樣。

## 怎麼渲染一張圖、存檔（F12、Save As）
1. 確認有作用中的攝影機（Numpad 0 看得到畫面）
2. 按 F12（或 Render › Render Image），會跳出渲染視窗
3. 在渲染視窗 Image › Save As（Shift + Alt + S）存成 PNG 或 JPG
- F11：重新叫出上一次的渲染結果
- 渲染視窗上方的 Slot 可以切換渲染槽，比較不同設定的結果（按 J 切換）
筆電的 F12 可能是系統功能鍵，需要按 Fn + F12。

## Cycles 渲染很慢、有很多雜點（Samples、Noise、Denoise）
Render Properties › Sampling：
- Render › Max Samples：取樣數，越高雜點越少但越慢（一般 128～512 加上降噪就夠）
- Noise Threshold：噪點門檻（預設 0.01），數值越大越早停止、越快
- Denoise：勾選降噪，OpenImageDenoise 品質好（CPU、新版也支援 GPU），OptiX 是 NVIDIA 顯卡專用、速度快
- Viewport 的 Samples 和 Denoise 是分開設定的，可以調低讓視窗預覽順一點
其他加速方法：Light Paths 的 Max Bounces 調低、解析度 % 測試時先用 50%、使用 GPU 渲染。

## 用顯示卡渲染（GPU、CUDA、OptiX）
Cycles 預設用 CPU，改用顯示卡通常快很多：
1. Edit › Preferences › System › Cycles Render Devices：NVIDIA 選 OptiX（RTX 系列）或 CUDA、AMD 選 HIP、Intel 選 oneAPI、Mac 選 Metal，勾選你的顯示卡
2. Render Properties › Device 改成 GPU Compute
找不到顯示卡：更新顯示卡驅動；顯卡太舊可能不支援新版 Blender 的 GPU 渲染。
筆電要確認 Blender 是用獨立顯卡執行（Windows 設定 › 顯示器 › 圖形，把 Blender 設為「高效能」）。

## 背景透明輸出去背圖（Film Transparent、PNG RGBA）
Render Properties › Film › 勾選 Transparent，背景就會變成透明。
存檔要用 PNG 並選 RGBA（Output Properties › Output 或存檔視窗裡設定），JPG 不支援透明。
透明背景下 HDRI 仍會照亮物件，只是不顯示。

## 只渲染畫面的一部分（Render Region、Ctrl + B）
在攝影機視角按 Ctrl + B 框選範圍，渲染時只算框起來的部分，適合局部測試。
Ctrl + Alt + B 取消。也可以在 Output Properties › Format 勾選 Render Region 確認狀態。

## 光線反彈次數（Light Paths、Bounces）
Cycles 的 Render Properties › Light Paths › Max Bounces：
- Total：光線最多反彈幾次
- Diffuse、Glossy、Transmission：各類型的反彈次數
- 玻璃後面看起來黑黑的：Transmission 的次數要夠（例如 8～12）
- 室內場景太暗：Diffuse 次數可以增加
- 只做簡單場景時可以調低加快速度
Caustics（焦散）預設不完整，Filter Glossy 可以減少亮點雜訊（Firefly）。

## 渲染出現亮白色雜點（Fireflies）
亮白小點常出現在玻璃、金屬、小光源附近。解法：
- Light Paths › Clamping › Indirect Light 設 10 左右
- Filter Glossy 設 1 左右
- 光源加大（Radius、Size），避免太小太強的光
- 開啟 Denoise、增加 Samples

## 渲染動畫（Render Animation、Ctrl + F12）
1. Output Properties › Frame Start / End 設定範圍，Frame Rate 設定幀率
2. Output 面板設定輸出資料夾和檔名（預設是 /tmp\，Windows 會存到 C:\tmp\）
3. File Format 選 PNG（輸出圖片序列，最推薦）或 FFmpeg Video（直接輸出影片）
4. Render › Render Animation（Ctrl + F12）
推薦先輸出 PNG 序列：中途當機只要從斷掉的那一格繼續，最後再用剪輯軟體或 Blender 的影片編輯器合成影片。
動畫渲染中按 Esc 可以停止。勾選 Overwrite 取消、Placeholders 勾選，可以多台電腦分工或接續渲染。

## 動態模糊（Motion Blur）
Render Properties › Motion Blur 勾選，快速移動的物件會有拖影，動畫比較自然。Shutter 越大拖影越長。
只有渲染動畫或渲染單格時看得到，視窗預覽不會顯示。

## 新版 Eevee 設定重點（Eevee Next、4.2 以後）
- Raytracing：勾選後反射、間接光更真實（比較慢）
- Shadows：陰影品質設定（Rays、Steps、Resolution）
- 舊教學中的 Bloom、Screen Space Reflections、Ambient Occlusion 勾選框在 4.2 已移除：反射改用 Raytracing、光暈改用合成器 Glare 節點
- 材質的 Settings 面板變成 Render Method（Dithered / Blended）
- Volumes、Light Probes（Volume、Sphere、Plane）用來改善室內光和反射

## 線條渲染、描邊（Freestyle、Line Art）
- Freestyle：Render Properties › Freestyle 勾選，渲染時自動畫出輪廓線，View Layer Properties 可以調線條粗細和類型
- Line Art：Shift + A › Grease Pencil › Scene Line Art 或 Object Line Art，產生可以編輯、即時看到的線條
建築圖、漫畫風、技術插畫常用。

## 渲染全黑、什麼都沒有
依序檢查：
- 有沒有作用中的攝影機、攝影機是否朝向物件（Numpad 0 看看）
- 有沒有燈光，或 World 是否全黑
- 物件在 Outliner 的相機圖示（Disable in Renders）是否被關掉
- 物件的修改器渲染開關（相機圖示）是否被關掉
- 攝影機的 Clip Start / End 範圍是否涵蓋物件
- Color Management 的 Exposure 是否被調得太低
