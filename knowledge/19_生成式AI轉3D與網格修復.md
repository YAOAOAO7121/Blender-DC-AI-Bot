# 生成式 AI 轉 3D 與網格修復（AI-to-3D、Mesh Cleanup）
<!-- 對應課程第 10～11 週。AI 工具更新很快，工具名稱僅供參考，以老師課堂介紹為準 -->

## AI 生成 3D 是什麼（Text to 3D、Image to 3D）
生成式 AI 可以從文字描述或一張圖片，自動產生 3D 模型（含貼圖）：
- 文字生成 3D（Text to 3D）：輸入描述，例如「一張木頭椅子，低多邊形風格」
- 圖片生成 3D（Image to 3D）：上傳一張圖，AI 推測看不到的背面、產生立體模型（目前品質通常比文字好控制）
- 多視角生成：上傳同一物件的前、側、後多張圖，結果更準確
常見的線上服務或開源模型有 Meshy、Tripo、Rodin（Hyper3D）、Hunyuan3D、TRELLIS 等，大多可以下載 GLB、FBX、OBJ。

## 圖片生成 3D 的輸入圖怎麼準備
- 主體完整、置中，不要被裁切或遮擋
- 背景單純（純白或去背）
- 光線平均、不要有強烈陰影或反光
- 角色用正面、A-pose 或 T-pose，手腳和身體分開，比較好做後續綁定
- 一張圖只放一個物件
- 斜 45 度的視角有時比正面更能讓 AI 理解立體感
可以先用 AI 繪圖產生「乾淨的三視圖」或白底單一物件，再拿去轉 3D。

## AI 生成的模型匯入 Blender（GLB 匯入）
1. 下載 GLB（推薦，貼圖會包在裡面）或 FBX / OBJ
2. File › Import › glTF 2.0 (.glb/.gltf)
3. 切到 Material Preview 檢查貼圖
4. 常需要調整：方向（R X 90）、大小（S 並套用 Ctrl + A）、原點（右鍵 › Set Origin › Origin to Geometry）
5. 放到地面上：把原點設到底部，或 N 面板調整 Z 位置

## 檢查 AI 模型的品質（網格品質檢視）
匯入後依序檢查：
- 面數：Viewport Overlays › Statistics，AI 模型常常幾十萬面，太重
- 佈線：切到 Wireframe（Z › Wireframe）看，AI 模型通常是密密麻麻的三角面，不適合直接細分或做動畫
- 法線：Viewport Overlays › Face Orientation，有紅色的地方是法線反了
- 破洞與非封閉網格：編輯模式 Select › Select All by Trait › Non Manifold
- 重疊點：M › By Distance 看合併了多少點
- 貼圖：光影是否被「畫」在貼圖上（Baked Lighting），打光時會很奇怪
- 細節：手指、文字、細小結構常常黏在一起或變形
- 對稱性、比例是否正確

## AI 模型可用性怎麼判斷
依用途決定能不能直接用：
- 背景小物、遠景、靜態擺設：通常減面後可以直接用
- 主角、近景特寫：細節常不夠，需要修貼圖或重做部分
- 要做動畫的角色：需要重新拓樸或至少乾淨的網格，再綁定（或丟 Mixamo 測試）
- 3D 列印：需要封閉、無破洞（Manifold）、有厚度
- 遊戲、網頁、AR：面數要低（幾千到幾萬面），貼圖解析度要控制
判斷三件事：外型對不對、網格能不能用、貼圖能不能用；修改的時間比自己做還久，就考慮手工建模。

## 清理網格（Mesh › Clean Up）
編輯模式 A 全選 › Mesh › Clean Up：
- Merge by Distance：合併重疊點（也可以 M › By Distance）
- Delete Loose：刪除沒有連接面的散落點和邊
- Degenerate Dissolve：移除面積為零、長度為零的壞面
- Fill Holes：自動補破洞
- Make Planar Faces：讓面變平
- Split Non-Planar Faces、Split Concave Faces：修正會造成著色問題的面
做完再 Shift + N 重新計算法線。

## AI 模型面太多、太重怎麼減面（Decimate、Remesh、QuadriFlow）
- Decimate 修改器：Collapse 模式調 Ratio（例如 0.1 = 留下 10% 面數），快速但都是三角面，貼圖大致保留
- Remesh 修改器（Voxel）：重建平均的網格，會失去 UV 和貼圖（需要重新烘焙）
- QuadriFlow Remesh（Object Data › Remesh › QuadriFlow Remesh）：自動重建四邊面網格，可以設定目標面數
- 想保留貼圖：先複製一份原始模型，新的低模展 UV 後把原始模型的顏色烘焙過來（Bake Diffuse，Selected to Active）

## 分離 AI 模型的零件（Separate by Loose Parts）
AI 模型常常整個黏成一塊，或很多小碎片：
- 編輯模式 P › By Loose Parts：每個不相連的部分變成獨立物件
- 刪除不要的碎片、浮空的雜點
- 想把黏在一起的部分切開：用 Knife（K）或布林、或重新建模

## 修破洞、補面（Fill Holes、Grid Fill）
- 自動：Mesh › Clean Up › Fill Holes
- 選取破洞的邊緣（Alt + 左鍵點邊界）› F 補面，或 Face › Grid Fill 補成整齊網格
- 找破洞：Select › Select All by Trait › Non Manifold，會選出所有開口邊

## 3D 列印前的檢查（3D Print Toolbox）
3D Print Toolbox 外掛可以檢查是否封閉、厚度是否足夠、有沒有交錯的面：
4.2 以後從 Edit › Preferences › Get Extensions 搜尋安裝（需要允許連網），之後在 N 側邊欄出現 3D-Print 分頁，按 Check All。
列印用 STL 或 3MF 匯出，單位要確認是公釐（mm）還是公尺。

## AI 模型的版權與使用條款
- 各家 AI 平台對生成結果的授權規定不同（免費方案可能不能商用、可能被公開）
- 上傳他人的圖片、角色、商標去生成可能侵權
- 作品發表時建議註明使用了哪些 AI 工具
請在使用前閱讀各平台的服務條款。
