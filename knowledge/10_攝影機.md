# 攝影機（Camera）與鏡頭語言
<!-- 對應課程第 5 週「攝影機語言」、第 13 週鏡頭匹配。適用 Blender 4.x / 5.x -->

## 新增攝影機、切換到攝影機視角（Numpad 0）
- Shift + A › Camera：新增攝影機
- Numpad 0：從攝影機看出去（沒有數字鍵盤可用 `~` 圓盤選單 › Camera）
- 渲染（F12）時用的是「作用中的攝影機（Active Camera）」，場景裡有多台時：選取那台攝影機按 Ctrl + Numpad 0 設為作用中
- 也可以在 Scene Properties › Camera 指定

## 讓攝影機對準現在的畫面（Ctrl + Alt + Numpad 0、Camera to View）
- 先調好視角 › 選取攝影機 › Ctrl + Alt + Numpad 0：攝影機直接移到目前的視角
- 更方便的方法：在攝影機視角中按 N › View 分頁 › 勾選 Camera to View（鎖定攝影機到視角），之後用滑鼠中鍵旋轉、平移、滾輪都會直接移動攝影機，調好後記得取消勾選
- 也可以在攝影機視角中選取攝影機，用 G、R 移動，連按 G Z Z 前後推近

## 焦距與廣角、望遠（Focal Length、mm）
攝影機 Properties（綠色攝影機圖示）› Lens › Focal Length：
- 14～24mm：廣角，空間感強、透視誇張，近距離拍人臉會變形
- 35mm：接近人眼的自然視角，常用在敘事場景
- 50mm：標準鏡頭
- 85～135mm：望遠，背景壓縮、透視較平，適合人像特寫
- Type 改成 Orthographic：正交攝影機，沒有透視，適合等角視角（Isometric）、建築立面圖

## 景深、背景模糊（Depth of Field、光圈 F-Stop）
攝影機 Properties › Depth of Field › 勾選：
- Focus on Object：選擇要對焦的物件（最方便），或用 Focus Distance 設距離
- F-Stop：光圈數字越小，背景越模糊（例如 1.4 很模糊、8 幾乎都清楚）
- 景深效果和真實比例有關：模型做太大或太小，模糊程度會不正常
在 Viewport Display 勾選 Limits 可以看到對焦距離的位置。

## 輸出解析度和畫面比例（Resolution、16:9、直式）
Output Properties（印表機圖示）› Format：
- 1920 × 1080：Full HD 橫式 16:9
- 3840 × 2160：4K
- 1080 × 1920：直式（Reels、Shorts、TikTok）
- 1080 × 1080：正方形
- % 欄位：渲染時的縮放比例，測試時可以設 50% 加快速度
攝影機框外的暗區可以在攝影機 Properties › Viewport Display › Passepartout 調深淺。

## 構圖輔助線（三分法 Composition Guides）
攝影機 Properties › Viewport Display › Composition Guides，可以開啟：
- Thirds：三分法，把主體放在線或交叉點上
- Center：中心構圖
- Golden：黃金比例
- Diagonal：對角線
- Safe Areas：安全框，避免重要內容被裁切

## 鏡頭景別（遠景、全景、中景、近景、特寫）
- 大遠景（Extreme Long Shot）：交代環境，人物很小
- 遠景／全景（Long / Full Shot）：拍到人物全身和周圍環境
- 中景（Medium Shot）：腰部以上，最常用的敘事鏡頭
- 近景（Medium Close-Up）：胸部以上
- 特寫（Close-Up）：臉部，強調情緒
- 大特寫（Extreme Close-Up）：眼睛、手、物件細節
景別由遠到近通常代表「從交代環境到聚焦情緒」。

## 鏡頭角度（俯角、仰角、荷蘭角）
- 平視（Eye Level）：中性、客觀
- 俯角（High Angle）：從上往下拍，主體顯得渺小、脆弱
- 仰角（Low Angle）：從下往上拍，主體顯得高大、有威脅感
- 鳥瞰（Bird's Eye）：正上方往下看，交代空間配置
- 荷蘭角（Dutch Angle）：攝影機傾斜，表現不安、混亂（攝影機沿自己的 Z 軸旋轉：選取攝影機 R Z Z）
- 過肩鏡頭（Over the Shoulder）：從一個角色肩後拍另一個角色，常用在對話

## 攝影機運動（推軌、搖鏡、橫移、升降）
- Pan（水平搖鏡）：攝影機位置不動，左右轉
- Tilt（垂直搖鏡）：位置不動，上下轉
- Dolly（推軌）：攝影機整台往前或往後移動
- Truck（橫移）：攝影機整台左右移動
- Pedestal / Crane（升降）：攝影機上下移動
- Zoom（變焦）：改焦距；和 Dolly 不同，Zoom 不會改變透視關係
- 推軌變焦（Dolly Zoom、希區考克變焦）：一邊後退一邊拉長焦距，主體大小不變但背景急遽變化
在 Blender 用關鍵影格（I）記錄攝影機的位置、旋轉或焦距就能做出這些運動。

## 攝影機一直對準某個物件（Track To 約束）
選取攝影機 › Object Constraint Properties › Add Object Constraint › Track To › Target 選要追蹤的物件（建議用一個空物件 Empty，方便移動）。
之後不管攝影機怎麼移動，都會一直對準目標。另一種做法是 Damped Track。

## 攝影機沿路徑移動（Follow Path）
1. 新增一條曲線（Shift + A › Curve › Path 或 Bezier）當軌道
2. 攝影機加 Follow Path 約束 › Target 選曲線 › 按 Animate Path
3. 曲線的 Object Data › Path Animation › Frames 設定走完整條路徑要幾格
搭配 Track To 約束讓攝影機邊移動邊看著主角。勾選 Follow Curve 會讓攝影機轉向前進方向。

## 手持攝影機晃動感（Camera Shake、Noise 修改器）
1. 先在攝影機的旋轉打一個關鍵影格
2. 到 Graph Editor 選取旋轉的曲線 › 右側 N 面板 › Modifiers › Add Modifier › Noise
3. 調 Scale（晃動速度，越大越慢）和 Strength（晃動幅度）
也可以讓攝影機成為一個空物件的子物件，只對空物件加晃動，比較好控制。

## 多台攝影機切換鏡頭（Bind Camera to Markers）
1. 在時間軸（Timeline）想切換的那一格按 M 新增標記（Marker）
2. 選取要使用的攝影機 › 選取標記 › Ctrl + B（Marker › Bind Camera to Markers）
3. 播放時就會在標記處自動切換攝影機
做完一整段動畫直接一次渲染出剪好的鏡頭。

## 攝影機看不到遠處或近處被切掉（Clip Start、Clip End）
攝影機 Properties › Lens › Clip Start / Clip End：
- 遠處的東西不見：把 Clip End 調大
- 攝影機靠近物件時被切掉：把 Clip Start 調小
這是攝影機的設定，和視窗的 Clip（N › View）是分開的。
