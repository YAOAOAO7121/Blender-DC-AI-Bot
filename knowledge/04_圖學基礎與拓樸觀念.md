# 圖學基礎與拓樸觀念

## 點、線、面是什麼（網格結構 Mesh、Vertex、Edge、Face）
Blender 的模型大多是「網格（Mesh）」，由三種元素組成：
- 點（Vertex，頂點）：空間中的一個座標位置
- 線（Edge，邊）：連接兩個點
- 面（Face）：由 3 個以上的邊圍起來的平面，會被算圖出來的是「面」
只有點和線、沒有面的部分，渲染時是看不到的。

## 三角面、四邊面、多邊面（Tris、Quads、N-gons）
- 四邊面（Quad）：最推薦，切線（Ctrl + R）、細分（Subdivision）、變形動畫都最順
- 三角面（Tri）：遊戲引擎最後都會轉成三角面，本身沒有錯，但放在曲面上細分會出現皺褶
- 多邊面（N-gon，5 個邊以上）：平面上可以用，但放在彎曲的地方容易出現奇怪的陰影、細分後凹凸不平
原則：要細分、要做動畫的模型盡量用四邊面；平的、不會變形的地方可以接受多邊面。
檢查方式：右上角 Viewport Overlays › 勾選 Statistics，可以看到點、邊、面、三角面的數量。

## 拓樸、佈線是什麼（Topology、Edge Flow）
拓樸指的是「點線面怎麼連接、線怎麼走」。好的佈線：
- 以四邊面為主，線條順著形狀的走向（例如臉的眼睛、嘴巴周圍是一圈一圈的環狀線）
- 密度平均，需要細節或會彎曲的地方（關節）線多一點，平坦的地方線少一點
- 盡量避免一個點連接 5 條以上的邊（極點 Pole），真的需要時放在平坦、不明顯的地方
同樣外型的模型，佈線好的比較好改、好展 UV、好做動畫。

## 法線是什麼（Normal）
法線是每個面「朝外的方向」，Blender 靠法線判斷哪一面是正面，影響打光、陰影和布林運算。
- 查看法線：Viewport Overlays › Face Orientation，藍色是正面、紅色是背面（反了）
- 顯示法線方向：編輯模式下 Viewport Overlays › Normals 可以畫出法線的小線段
- 修正法線：編輯模式 A 全選 › Shift + N 重新計算朝外；Alt + N 可以手動翻轉（Flip）
法線反了常見症狀：面變黑、打光怪怪的、匯出到其他軟體面消失、布林運算失敗。

## 座標系與 XYZ 軸（Global、Local、Z 軸朝上）
- Blender 是 Z 軸朝上：紅色 X 軸（左右）、綠色 Y 軸（前後）、藍色 Z 軸（上下）
- 全域座標（Global）：整個世界的方向，永遠不變
- 區域座標（Local）：物件自己的方向，物件轉了它也跟著轉
- 移動時按一次 X 是沿全域 X 軸，連按兩次 X 是沿物件自己的 X 軸
- 畫面上方的 Transform Orientation 下拉選單可以切換 Global / Local / Normal / View 等
注意：Unity 是 Y 軸朝上，匯出 FBX 時通常會自動轉換（Forward / Up 選項）。

## 單位與尺寸（Units、公尺、真實比例）
Blender 預設 1 單位 = 1 公尺，預設方塊是 2 m × 2 m × 2 m。
建模時盡量用真實尺寸（人約 1.7 m、門約 2 m 高），打光、物理模擬、景深才會正確。
- 修改單位：Properties › Scene › Units（可以改成公分顯示）
- 精準設定尺寸：N 側邊欄 › Item › Dimensions 直接輸入
- 改完尺寸記得 Ctrl + A › Scale 套用縮放

## 物件模式和編輯模式的縮放差別（Object Mode vs Edit Mode）
- 物件模式縮放：只改「縮放值」，網格本身沒變，所以縮放值不再是 1（需要 Ctrl + A 套用）
- 編輯模式縮放：直接改網格的點的位置，縮放值維持 1
修改器、倒角、UV、物理模擬都是看「網格＋縮放值」，所以物件模式縮放後沒套用，效果常常會變形。

## 面數與效能（Poly Count、低模高模）
- 低模（Low Poly）：面數少，適合遊戲、即時互動、網頁
- 高模（High Poly）：面數多、細節多，適合算圖、雕刻
常見做法：雕刻出高模 → 重新拓樸成低模 → 把高模細節「烘焙」成法線貼圖貼回低模。
面數越多電腦越卡；Statistics 可以看目前的面數。一般單一道具幾千到幾萬面、角色幾萬面是常見範圍。
