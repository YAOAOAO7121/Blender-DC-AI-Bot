# 建模進階工具（編輯模式 Edit Mode）
<!-- 補充 03_建模入門 沒有的工具。適用 Blender 4.x / 5.x -->

## 更多選取方法（框選 B、圈選 C、加選、選取相似）
- Shift + 左鍵：加選／取消選取
- 左鍵拖曳或 B：框選；C：圓圈刷選（滾輪改圓圈大小，右鍵或 Esc 結束）
- Ctrl + 左鍵：選取兩點之間的最短路徑
- Ctrl + Numpad + / Ctrl + Numpad -：擴大／縮小選取範圍
- Ctrl + L：選取相連的部分（和 L 類似，但以目前選取為基準）
- Ctrl + I：反向選取
- Shift + G：選取相似（相同面積、相同法線方向等）
- Select › Checker Deselect：每隔一個取消選取（做間隔造型很好用）
- Alt + 左鍵：選取一整圈；Ctrl + Alt + 左鍵：選取環狀面（Ring）

## 刀具切割（K，Knife）
按 K 進入刀具，在模型上點擊畫出切割線，Enter 確定、Esc 取消。
- 切割時按 Z：穿透切割（連背面一起切）
- 按 C：角度鎖定（每 45 度）
- 按住 Ctrl：吸附到邊的中點
適合在任意位置加線，但容易產生多邊面或三角面，切完記得檢查佈線。

## 邊滑移、點滑移（G G，Edge Slide、Vertex Slide）
- 選取邊或點，快速按兩次 G：沿著旁邊的邊滑動，不會改變外型
- Shift + V：點滑移（Vertex Slide）
常用在調整切線位置，比直接 G 移動安全。

## 刪除和溶解的差別（X，Delete、Dissolve）
按 X 會出現選單：
- Vertices / Edges / Faces：刪除點／邊／面，周圍的面會跟著破洞
- Dissolve Vertices / Edges / Faces：溶解，移除選取的元素但「保留面不破洞」
- Only Faces：只刪面，保留邊框
想移除多餘的線又不想破洞，用 Dissolve（Ctrl + X 也可以直接溶解）。

## 橋接兩圈邊（Bridge Edge Loops）
選取兩圈數量相同的環狀邊 › 右鍵或 Edge 選單 › Bridge Edge Loops，會在中間自動補面連起來。
可以調整段數（Number of Cuts）、扭轉（Twist）、平滑度。常用在接管子、接手臂身體。

## 細分網格（Subdivide）
選取面或邊 › 右鍵 › Subdivide，把面平均切成更多小面，左下角面板可以調整切的次數（Number of Cuts）。
注意：Subdivide 只是切分、不會變圓；想讓物件變圓滑要用 Subdivision Surface 修改器（Ctrl + 1～5）。

## 沿法線擠出、個別擠出（Alt + E）
- E：一般擠出，整片一起往外拉
- Alt + E › Extrude Faces Along Normals：每個面沿各自的法線方向擠出（像充氣）
- Alt + E › Extrude Individual Faces：每個面各自擠出、彼此分開
- 只想往外推不想新增面：Alt + S（Shrink / Fatten 沿法線縮放）

## 比例編輯、軟選取（O，Proportional Editing）
按 O 開關比例編輯（畫面上方的同心圓圖示）。開啟後移動一個點，周圍的點也會平滑跟著動。
- 移動時滾動滾輪：改變影響範圍（出現的圓圈）
- 圖示旁的下拉選單可以改衰減方式（Smooth、Sphere、Sharp、Random…）
- 勾選 Connected Only：只影響相連的網格
常見問題：忘記關掉比例編輯，之後每次移動都會拉到一大片，按 O 關掉就好。

## 吸附（Shift + Tab，Snapping）
畫面上方的磁鐵圖示開關吸附，旁邊下拉選單選吸附對象：
- Increment：格線刻度
- Vertex：吸附到點；Edge：吸附到邊；Face：吸附到表面
- Snap Base（Closest / Center / Median / Active）：決定用自己的哪一點去吸附
移動時按住 Ctrl 可以暫時切換吸附開關。重新拓樸時常用 Face Project 吸附到表面。

## 旋轉成形（Spin、做杯子花瓶）
1. 用點和線畫出杯子的半邊剖面
2. 把 3D 游標放在旋轉中心（Shift + 右鍵）
3. 選取剖面 › 左側工具列 Spin，或 Edge › Spin，可以設定角度（360°）和段數
做完記得 M › By Distance 合併頭尾重疊的點。也可以改用 Screw 修改器，可以隨時調整。

## 撕開、分割（V Rip、Y Split）
- V：把選取的點／邊撕開，產生新的點，可以拉出開口
- Y：把選取的面從周圍分割出來（還在同一個物件裡）
- P › Selection：分割成另一個獨立物件

## 補洞、網格補面（Grid Fill、Fill）
- 選取一圈封閉的邊 › F：補一個多邊面
- Face › Grid Fill：補成整齊的四邊面網格（需要偶數個點），圓柱的頂面常用
- Alt + F：補成三角面

## 三角面轉四邊面（Ctrl + T、Alt + J）
- Ctrl + T：把選取的面轉成三角面（Triangulate）
- Alt + J：把三角面盡量合併成四邊面（Tris to Quads），整理 AI 生成或匯入的模型時常用

## 平滑著色、自動平滑（Shade Smooth、Shade Auto Smooth）
物件模式選取物件 › 右鍵：
- Shade Flat：每個面都看得到稜角
- Shade Smooth：表面看起來平滑（只是顯示效果，面數不變）
- Shade Auto Smooth：依照角度決定哪裡平滑、哪裡保留銳利邊（4.1 以後會自動加上 Smooth by Angle 修改器，可以調角度）
舊教學裡的「Object Data › Normals › Auto Smooth」在 4.1 以後已經移除，改用上面的方法。
平滑後出現奇怪的黑色條紋：通常是多邊面、重疊點或法線問題，或需要用 Auto Smooth 保留銳利邊。

## 標記銳利邊、摺痕（Mark Sharp、Crease Shift + E）
- Edge › Mark Sharp：配合 Auto Smooth，讓這條邊保持銳利的著色
- Shift + E：邊摺痕（Crease），讓 Subdivision Surface 細分時這條邊保持銳利，數值 0～1

## 對稱建模（X 軸鏡像編輯）
- 編輯模式右上角的蝴蝶圖示 › 勾選 X：修改一邊的點，另一邊對應的點會一起動（模型需要本來就對稱）
- 更推薦的方法：刪掉一半模型，加 Mirror 修改器（請看「修改器」筆記）

## 點對齊成一直線或平面（S X 0）
選取多個點 › S › X › 0 › Enter：把所有點在 X 方向壓平成一條直線／一個平面。
Y、Z 軸同理。拿來把歪掉的邊整理對齊很好用。

## 中心點、變換中心（Pivot Point，按 . 句號）
按 .（句號）叫出 Pivot Point 圓盤選單，決定旋轉縮放的中心：
- Median Point：選取範圍的中心（預設）
- Individual Origins：每個面／物件各自以自己的中心縮放
- 3D Cursor：以 3D 游標為中心
- Active Element：以最後選取的元素為中心
