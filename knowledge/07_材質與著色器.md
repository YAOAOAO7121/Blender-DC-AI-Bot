# 材質與著色器（Material、Shader）
<!-- 對應課程第 3～5 週。適用 Blender 4.x / 5.x（Principled BSDF 為 4.0 以後的版本） -->

## 怎麼看到材質顏色（視窗著色模式 Viewport Shading、Z）
畫面右上角四顆球，或按 Z 叫出圓盤選單：
- Wireframe：線框
- Solid：實體（預設，看不到材質，只有灰色）
- Material Preview：材質預覽，可以看到材質和貼圖
- Rendered：用目前的渲染引擎即時算圖，可以看到燈光效果
做材質時切到 Material Preview 或 Rendered 才看得到顏色。

## 新增材質、改顏色（New Material、Base Color）
選取物件 › Properties 的紅色球圖示（Material Properties）› New。
最簡單的改顏色：Surface › Base Color 點色塊選顏色。
一個材質可以給很多物件共用，改一個全部會一起變；不想一起變時，按材質名稱旁的數字讓它變成單獨一份。

## 一個物件用多種材質（Material Slot、Assign）
1. 在 Material Properties 的清單右邊按 + 新增材質槽（Slot），再為它新增材質
2. 進入編輯模式，選取要上色的面
3. 在清單中選好材質 › 按 Assign
沒有被指定的面會用第一個材質。

## 把材質複製給其他物件（Link Materials、Ctrl + L）
先選要被套用的物件們，最後選有材質的物件（變成亮橘色）› Ctrl + L › Link Materials。
也可以在材質清單下拉選單選已經存在的材質。

## 原理化 BSDF 主要參數（Principled BSDF）
Principled BSDF 是萬用材質節點，大部分材質用它就做得出來：
- Base Color：基本顏色
- Metallic：金屬度，0 = 非金屬（塑膠、木頭），1 = 金屬，通常只用 0 或 1
- Roughness：粗糙度，0 = 光滑像鏡子，1 = 霧面
- IOR：折射率（玻璃約 1.45～1.5、水 1.33）
- Alpha：透明度
- Normal：接法線貼圖或凹凸（Bump）
- Subsurface：次表面散射，做皮膚、蠟燭、玉石等光會透進去的材質
- Specular › IOR Level：反光強度
- Transmission › Weight：透射，玻璃設為 1
- Coat：清漆層（車漆、亮光漆）
- Sheen：絨布光澤（布料、絨毛）
- Emission › Color / Strength：自發光
4.0 以前的舊教學參數名稱不太一樣（例如 Transmission、Emission 直接在外層），找不到時展開面板或用 F3 搜尋。

## 常見材質怎麼調（塑膠、金屬、玻璃、橡膠）
- 塑膠：Metallic 0、Roughness 0.3～0.5
- 拋光金屬：Metallic 1、Roughness 0.1～0.2，Base Color 決定金屬顏色（金色、銅色）
- 霧面金屬：Metallic 1、Roughness 0.4～0.6
- 玻璃：Transmission Weight 1、Roughness 0、IOR 1.45
- 橡膠：Metallic 0、Roughness 0.8～1，顏色偏暗
- 陶瓷：Metallic 0、Roughness 0.1～0.2、加一點 Coat
金屬材質在沒有環境可以反射時會看起來很暗，記得加 HDRI 環境光或周圍有東西可以反射。

## 玻璃在 Eevee 看起來不透明（Eevee 透明、折射）
Cycles 的玻璃設定好就會正確；Eevee 需要額外設定：
- 4.2 以後（新版 Eevee）：Render Properties 開啟 Raytracing，材質 Settings 的 Render Method 選 Dithered，並勾選 Raytraced Transmission
- 4.1 以前：Render Properties 勾選 Screen Space Refraction，材質 Settings 勾選 Screen Space Refraction
想要準確的玻璃效果，建議用 Cycles 渲染。

## 自發光、霓虹燈、發光效果（Emission、Bloom、Glare）
Principled BSDF 的 Emission Color 設顏色、Emission Strength 調大（例如 5～20），物件就會發光。
- Cycles：自發光物件會真的照亮周圍
- Eevee：4.2 以後也會照亮周圍（強度較弱）
- 光暈效果（Bloom）：4.2 以後 Eevee 拿掉了 Bloom 勾選框，改在合成器（Compositor）加 Glare 節點，類型選 Bloom 或 Fog Glow；Cycles 一直都是用 Glare 節點
也可以用 Emission 節點代替 Principled BSDF，做純發光的燈條。

## 透明貼圖、去背圖片（Alpha、PNG 透明）
1. Image Texture 節點的 Alpha 輸出接到 Principled BSDF 的 Alpha
2. Eevee 需要再設定：4.2 以後材質 Settings › Render Method 選 Dithered 或 Blended；4.1 以前 Blend Mode 選 Alpha Clip 或 Alpha Hashed
Cycles 不用額外設定。陰影也透明的話，4.1 以前另外調 Shadow Mode。

## 著色器編輯器怎麼用（Shader Editor、節點 Node）
上方切到 Shading 工作區，下半部就是 Shader Editor，材質由節點（Node）連接而成。
- Shift + A：新增節點（也可以直接打字搜尋）
- 拖曳節點的輸出圓點到另一個節點的輸入圓點：連線
- Ctrl + 右鍵拖曳：切斷連線
- 按住 Alt 拖曳節點：把節點從連線中拉出來
- 拖曳節點到線上：自動插入
- Ctrl + G：把選取節點變成群組；Tab 進出群組
- M：靜音節點（暫時停用）
- 最後一定要接到 Material Output 的 Surface 才會生效
顏色相近的接口才互接：黃色是顏色、灰色是數值、紫色是向量（座標、法線）、綠色是著色器。

## Node Wrangler 外掛（節點快捷工具）
Blender 內建但預設沒開啟的外掛，強烈推薦開啟：Edit › Preferences › Add-ons › 搜尋 Node Wrangler › 勾選。
- Ctrl + Shift + 左鍵點節點：快速預覽這個節點的結果
- 選取 Principled BSDF › Ctrl + Shift + T：一次選取多張 PBR 貼圖自動接好（顏色、粗糙度、法線…）
- 選取 Image Texture › Ctrl + T：自動加上 Texture Coordinate 和 Mapping 節點，方便調整貼圖位置大小

## 程序化紋理（Procedural Texture、Noise、Voronoi）
不用圖片、用數學產生的紋理，解析度無限而且不需要 UV：
- Noise Texture：雜訊，做髒污、雲、不規則變化
- Voronoi Texture：細胞狀，做石磚、皮革、水波
- Wave Texture：波浪條紋，做木紋
- Gradient Texture：漸層
- Brick Texture、Checker Texture：磚牆、棋盤格
常見組合：Noise Texture › Color Ramp（控制黑白對比與顏色）› 接到 Base Color 或 Roughness。

## 色彩漸層節點（Color Ramp）
把黑白數值轉換成指定的顏色，或調整對比：
- 點色標可以改顏色，按 + 新增色標
- 把兩個色標拉近 → 對比變強、邊緣變銳利
- Interpolation 改成 Constant → 變成色塊分明（卡通風格常用）

## 凹凸效果（Bump、Normal Map 節點）
- Bump 節點：接黑白紋理（例如 Noise）到 Height，Bump 的 Normal 輸出接到 Principled BSDF 的 Normal，表面會看起來凹凸
- Normal Map 節點：接法線貼圖（藍紫色的圖），圖片的 Color Space 要設成 Non-Color
- Strength 調整凹凸強度
這只是「看起來」凹凸，輪廓不會改變；真正改變形狀要用 Displacement 或 Displace 修改器。

## 卡通渲染、二次元風格（Toon Shader、Shader to RGB）
在 Eevee 中：Diffuse BSDF › Shader to RGB › Color Ramp（Interpolation 設 Constant）› Material Output，可以做出色階分明的卡通陰影。
描邊：物件加 Solidify 修改器並勾 Flip Normals、配一個背面剔除的黑色材質（反轉外殼法），或用 Line Art / Freestyle。
Shader to RGB 只能在 Eevee 使用。

## 材質顯示成粉紅色（Missing Texture）
粉紅色代表 Blender 找不到貼圖圖片（圖片被移動、改名，或檔案從別人的電腦複製過來）。
解法：File › External Data › Find Missing Files，選擇圖片所在的資料夾；或在 Image Texture 節點重新開啟圖片。
預防：交檔前用 File › External Data › Pack Resources 把圖片打包進 .blend 檔。

## 材質庫、現成材質去哪裡找
- Poly Haven（polyhaven.com）：免費 CC0 的材質、HDRI、模型
- ambientCG（ambientcg.com）：免費 CC0 PBR 材質
- Blender 內建的 Asset Browser 也可以存放自己的材質庫
下載的 PBR 材質通常有 Color、Roughness、Normal、Displacement 等多張圖，用 Node Wrangler 的 Ctrl + Shift + T 一次接好。
