# 安裝、設定與效能（Install、Preferences、Performance）
<!-- 適用 Blender 4.x / 5.x -->

## 下載安裝 Blender、要裝哪個版本
- 官方網站 blender.org 免費下載（Windows 安裝檔、免安裝的 zip、macOS、Linux），也可以從 Steam、Microsoft Store 安裝
- LTS（Long Term Support）版本會維護兩年，比較穩定，例如 4.2 LTS、4.5 LTS
- 不同版本可以同時存在同一台電腦，免安裝的 zip 版解壓縮就能用
- 上課使用的版本以老師指定為準；不確定時用和老師相同的版本，介面和教學才會一致
- 5.0 以後不支援 Intel 處理器的 Mac

## 介面改成中文（Language、繁體中文）
Edit › Preferences › Interface › Translation › Language 選「繁體中文（Traditional Chinese）」：
- 下方勾選要翻譯的項目：Tooltips（提示）、Interface（介面）、New Data（新物件的名稱）
- 建議不要勾 New Data，物件名稱維持英文，避免匯出到其他軟體時出現問題
注意：網路上大多數教學、快捷鍵說明、論壇都是英文介面，用中文介面時對照教學會比較辛苦；按 F3 搜尋功能時，中文介面也可以用英文搜尋。很多人會用英文介面但開啟中文提示（只勾 Tooltips），兩邊兼顧。

## 介面字太小（Resolution Scale）
Edit › Preferences › Interface › Display › Resolution Scale，調成 1.2～1.5 介面會整體放大。筆電螢幕或投影時常用。

## 偏好設定沒有存起來（Save Preferences）
Preferences 視窗左下角的選單 › 確認 Auto-Save Preferences 有勾選，或手動按 Save Preferences。
恢復預設：File › Defaults › Load Factory Settings（會重設偏好設定）。

## 安裝外掛、擴充功能（Add-ons、Extensions、Get Extensions）
- 4.2 以後：Edit › Preferences › Get Extensions，第一次需要允許網路存取（Allow Online Access），就能直接搜尋安裝官方擴充平台 extensions.blender.org 上的外掛
- 內建外掛（例如 Node Wrangler、Rigify）：Preferences › Add-ons 搜尋名稱勾選
- 自己下載的 zip 外掛：Add-ons 右上角下拉選單 › Install from Disk，選 zip 檔（不要解壓縮）
- 4.1 以前：Add-ons › Install 選 zip 檔
外掛有版本相容性，舊外掛可能不支援新版 Blender。

## 筆電、平板操作設定（Emulate 3 Button、觸控板）
Edit › Preferences › Input：
- Emulate 3 Button Mouse：Alt + 左鍵模擬中鍵
- Emulate Numpad：鍵盤上方數字鍵當數字鍵盤
- 觸控板：兩指滑動旋轉視角、Shift + 兩指平移、兩指縮放（依系統不同）
強烈建議買一個有滾輪的滑鼠，操作會順很多。

## 用左鍵還是右鍵選取（Keymap）
Blender 2.8 以後預設左鍵選取。舊教學（2.7x）是右鍵選取，看舊影片時要注意。
Preferences › Keymap 可以修改，也有 Industry Compatible（類似 Maya）的快捷鍵配置，但上課建議使用預設 Blender 配置，才和老師、教學一致。

## Blender 很卡、很慢怎麼辦（效能 Performance）
- 視窗切回 Solid 模式，只在需要時用 Material Preview / Rendered
- 降低 Subdivision Surface 的 Viewport 等級
- Render Properties › Simplify：勾選後可以一次限制整個場景的細分等級、粒子數量
- 隱藏（H）或排除不需要的集合
- 高面數模型用 Decimate 減面，或把遠處物件換成低模
- 物件顯示成方框：Object Properties › Viewport Display › Display As › Bounds
- 開啟 Statistics 看哪個物件面數特別多
- 確認 Blender 使用獨立顯卡、顯示卡驅動是最新的

## 電腦規格建議（顯示卡、記憶體）
- 記憶體 16 GB 以上比較順，8 GB 做簡單場景也可以
- 有獨立顯示卡（NVIDIA RTX 系列對 Cycles 最友善）渲染快很多
- 沒有獨立顯卡也能學建模、材質，渲染用 Eevee 或降低 Cycles 取樣
- 顯示卡記憶體（VRAM）不夠時，Cycles GPU 渲染會失敗，可以降低貼圖解析度或改用 CPU

## Blender 一直當機、閃退
- 更新顯示卡驅動（NVIDIA、AMD、Intel 官網）
- 試試 File › Defaults › Load Factory Settings 排除外掛問題
- 渲染時當機：可能是記憶體或顯示卡記憶體不足，降低解析度、貼圖、細分等級、取樣
- 當機前的進度：File › Recover › Auto Save 或 Recover Last Session
- 換一個版本（例如 LTS 版）試試看
