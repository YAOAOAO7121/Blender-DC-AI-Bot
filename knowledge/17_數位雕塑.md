# 數位雕塑（Sculpt Mode）

## 進入雕刻模式（Sculpt Mode）
上方切到 Sculpting 工作區，或左上角模式選單選 Sculpt Mode。
雕刻需要足夠的面數，方塊直接雕會很粗糙；可以先加 Subdivision 套用、用 Remesh，或開啟 Dyntopo。
有繪圖板（數位板）的話雕刻會順手很多，筆壓可以控制大小和強度（5.0 以後可以用曲線自訂筆壓反應）。

## 常用雕刻筆刷（Draw、Clay Strips、Grab、Smooth）
- Draw：往外推出（按住 Ctrl 往內凹）
- Clay Strips：像一層層堆黏土，塑造量體最常用
- Grab（G）：抓住一塊拉動，調整大形
- Smooth（按住 Shift 隨時切換）：撫平表面
- Inflate：膨脹；Crease：刻出深溝（皺紋、縫線）
- Pinch：收緊邊緣；Flatten：壓平；Scrape：刮平
- Snake Hook：拉出觸手、角
- Mask：遮罩，被遮的地方不會被雕到
4.3 以後筆刷變成資產（Brush Assets），在左側工具列或上方的筆刷選單切換。

## 筆刷大小和強度（F、Shift + F）
- F：調整筆刷大小（移動滑鼠後點擊確定）
- Shift + F：調整強度
- Ctrl：反向（凸變凹）
- Shift：暫時切換到 Smooth
- 上方工具列的筆壓圖示：開關數位板筆壓

## 左右對稱雕刻（Symmetry）
畫面右上角的蝴蝶圖示（或 Header 的 X Y Z 按鈕），X 預設開啟：雕一邊另一邊同步。
對稱是以物件原點為中心，原點不在中間的話會錯位。

## 動態拓樸（Dyntopo）
開啟後，筆刷畫到哪裡就自動在哪裡增加面，不用先細分整個模型。
- 上方 Dyntopo 勾選
- Detail Size：數字越小越細緻
- 適合自由造型、概念雕塑
- 缺點：會產生亂的三角面、清除 UV，做完通常要重新拓樸

## 體素重建網格（Voxel Remesh、Ctrl + R）
雕刻到面拉得很長、很不平均時：
- R：調整體素大小（Voxel Size），畫面會顯示網格密度
- Ctrl + R：執行重建，整個模型變成平均的網格
比 Dyntopo 更穩定，常用流程：粗雕 → Ctrl + R 重建 → 繼續雕 → 需要更細時把 Voxel Size 調小再重建。

## 多重解析度修改器（Multiresolution）
保留低模的同時增加雕刻細節：加 Multiresolution 修改器 › 按 Subdivide 增加等級，在高等級雕細節（毛孔、皺紋），隨時可以切回低等級。
可以用來烘焙法線貼圖。

## 遮罩與面組（Mask、Face Sets）
- Mask 筆刷（M）：塗上的地方不會被雕刻影響
- Alt + M：清除遮罩；Ctrl + I：反轉遮罩
- 遮罩後可以用 Mask › Extract 把遮罩區域變成新物件（做衣服、盔甲）
- Face Sets（面組）：把模型分區上色，Ctrl + Shift 點一下可以快速隔離顯示某一區，H 隱藏

## 雕刻時的材質球（MatCap）
雕刻時常用 MatCap 顯示，看清楚凹凸：
Viewport Shading 下拉選單 › Solid 模式 › Lighting 選 MatCap，點球可以換不同的材質樣式（紅土、灰黏土等）。
只影響顯示，不影響渲染。

## 高模、低模與法線烘焙（High Poly、Low Poly、Retopology）
雕刻出的模型通常有幾十萬到幾百萬面，太重不能拿來做動畫或遊戲：
1. 重新拓樸（Retopology）：在高模表面重建一個面數少、佈線好的低模（用 Snapping 的 Face Project 吸附、Shrinkwrap 修改器、Poly Build 工具，或自動的 QuadriFlow Remesh）
2. 低模展 UV
3. 把高模的細節烘焙成法線貼圖（請看「UV 展開與貼圖」筆記的烘焙段落）
4. 低模貼上法線貼圖，看起來就有高模的細節

## 雕刻很卡（效能）
- 面數太多：降低 Multires 等級、Voxel Size 調大
- 關閉 Material Preview，改用 Solid 模式
- 隱藏不需要的物件（H）或用 Face Sets 只顯示局部
- 關掉其他修改器的視窗顯示
