# 快捷鍵總表（Shortcuts、Hotkeys）
<!-- 預設 Blender 快捷鍵配置、左鍵選取。適用 Blender 4.x / 5.x -->

## 快捷鍵沒反應（中文輸入法、滑鼠位置）
- 最常見原因：輸入法在中文模式！按快捷鍵前先切成英文（按 Shift 或切換輸入法）
- 滑鼠要放在對應的區域上：例如 3D 視窗的快捷鍵，滑鼠要在 3D 視窗內
- 確認目前的模式（物件模式、編輯模式的快捷鍵不同）
- 筆電的 F1～F12 可能要搭配 Fn 鍵
- 數字鍵盤的快捷鍵（Numpad）在沒有數字鍵盤的筆電要開 Emulate Numpad

## 通用快捷鍵
- Ctrl + S：存檔；Ctrl + Shift + S：另存新檔
- Ctrl + Z：復原；Ctrl + Shift + Z：重做
- F3：搜尋功能
- F2：重新命名
- F12：渲染圖片；Ctrl + F12：渲染動畫
- Ctrl + Space：區域最大化
- N：右側側邊欄；T：左側工具列
- Shift + Space：工具選單
- Q：快速收藏選單（在功能上右鍵 › Add to Quick Favorites）
- Shift + R：重複上一個動作
- 滑鼠停在按鈕上：顯示說明（Tooltip）

## 視角快捷鍵
- 中鍵拖曳：旋轉；Shift + 中鍵：平移；滾輪：縮放
- Numpad 1 / 3 / 7：前 / 右 / 上視圖（加 Ctrl 是反方向）
- Numpad 5：透視 / 正交切換
- Numpad 0：攝影機視角
- Numpad .：對準選取的物件
- Numpad /：區域視圖（只顯示選取的物件）
- Home：顯示全部
- `（Esc 下方）：視角圓盤選單
- Z：視窗著色模式圓盤選單；Shift + Z：切換線框
- Alt + Z：X 光透視

## 物件模式快捷鍵
- Shift + A：新增物件
- G / R / S：移動 / 旋轉 / 縮放（之後按 X Y Z 鎖定軸向）
- Alt + G / R / S：位置 / 旋轉 / 縮放歸零
- Ctrl + A：套用變換（Apply）
- Shift + D：複製；Alt + D：關聯複製
- X / Delete：刪除
- H：隱藏；Alt + H：顯示全部；Shift + H：隱藏未選取
- Ctrl + J：合併物件
- Ctrl + P：設定父物件；Alt + P：清除父物件
- M：移動到集合
- Ctrl + L：連結（材質、修改器等）
- Shift + 右鍵：放置 3D 游標；Shift + C：游標歸零並顯示全部
- Shift + S：吸附選單（游標到選取、選取到游標）
- .（句號）：變換中心（Pivot Point）選單
- Ctrl + 1～5：加細分曲面

## 編輯模式快捷鍵
- Tab：進出編輯模式
- 1 / 2 / 3：點 / 邊 / 面選取
- A：全選；Alt + A：取消全選；Ctrl + I：反選
- Alt + 左鍵：選環狀邊；L：選相連
- E：擠出；I：內插面；Ctrl + B：倒角
- Ctrl + R：環切；K：刀具
- F：補面；M：合併
- G G：邊滑移；Shift + V：點滑移
- V：撕開；Y：分割；P：分離成新物件
- Alt + S：沿法線縮放
- Shift + N：重新計算法線
- Ctrl + T：轉三角面；Alt + J：三角轉四邊
- U：UV 選單（Unwrap、Mark Seam）
- O：比例編輯開關
- Shift + Tab：吸附開關
- Ctrl + X：溶解
- Shift + E：邊摺痕（Crease）

## 雕刻模式快捷鍵
- F：筆刷大小；Shift + F：強度
- Ctrl：反向；Shift：平滑
- G：Grab 筆刷；M：Mask 筆刷
- Alt + M：清除遮罩；Ctrl + I：反轉遮罩
- R：設定體素大小；Ctrl + R：體素重建網格

## 動畫快捷鍵
- I：插入關鍵影格；Alt + I：刪除關鍵影格；K：選擇記錄哪些屬性
- Space：播放 / 暫停
- Left / Right：前後一格；Up / Down：上下一個關鍵影格
- Shift + Left / Right：跳到開頭 / 結尾
- T：補間方式；V：把手類型；Ctrl + E：緩入緩出
- Shift + E：外插（循環、延續）
- M（時間軸）：新增標記；Ctrl + B：攝影機綁定標記

## 節點編輯器快捷鍵（Shader Editor、Compositor、Geometry Nodes）
- Shift + A：新增節點
- Ctrl + 右鍵拖曳：切斷連線
- Alt + 拖曳：把節點從連線中拉出
- Ctrl + G：建立群組；Tab：進出群組；Alt + G：解散群組
- M：靜音節點
- H：收合節點
- F：連接選取的節點
- Home：顯示全部節點
- Ctrl + Shift + 左鍵（Node Wrangler）：預覽節點
- Ctrl + T（Node Wrangler）：加貼圖座標
- Ctrl + Shift + T（Node Wrangler）：一次載入 PBR 貼圖
