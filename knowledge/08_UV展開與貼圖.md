# UV 展開與貼圖（UV Unwrap、Texture）
<!-- 對應課程第 3～4 週。適用 Blender 4.x / 5.x -->

## UV 是什麼（為什麼要展 UV）
UV 是把 3D 模型的表面「攤平」成 2D 的地圖，讓圖片知道要貼在模型的哪裡。
可以想像成把紙盒拆開攤平：U、V 是平面圖上的橫軸和縱軸（因為 X、Y、Z 已經被用掉了）。
需要 UV 的情況：使用圖片貼圖（Image Texture）、手繪貼圖、烘焙貼圖。
不需要 UV 的情況：只用純色或程序化紋理（Noise 等，預設會用 Generated 座標）。

## UV 編輯工作區（UV Editing）
上方切到 UV Editing 分頁：左邊是 UV 編輯器（2D），右邊是 3D 視窗（已自動進入編輯模式）。
在 3D 視窗選取面，左邊才會顯示那些面的 UV。
5.0 以後 UV Sync Selection 預設開啟，3D 視窗和 UV 編輯器的選取會同步。

## 標記接縫、切開 UV（Mark Seam）
接縫（Seam）是告訴 Blender「從這裡剪開」：
1. 編輯模式切到邊選取（2），選取要剪開的邊
2. 按 U › Mark Seam（或 Edge 選單 › Mark Seam），邊會變成紅色
3. 清除接縫：U › Clear Seam
接縫盡量放在不顯眼的地方（背面、底部、轉角、衣服縫線處），就像衣服版型的縫線。

## 怎麼展 UV、UV 展開步驟（U › Unwrap UV）
標好接縫後，A 全選 › U › Unwrap，Blender 會依照接縫把模型攤平。
U 選單裡常用的方法：
- Unwrap：依照接縫展開（最常用、品質最好）
- Smart UV Project：自動依角度切開展開，不用自己標接縫，快速但接縫很多，適合硬表面、道具、要烘焙的東西
- Cube Projection：像方塊六個面投影，適合方正的東西
- Cylinder / Sphere Projection：圓柱、球體投影
- Project from View：從目前視角投影，像投影機打在模型上
- Reset：每個面都佔滿整張圖

## 檢查 UV 有沒有拉伸（棋盤格 Checker、Stretch）
- 方法一：Image Texture 節點 › New › Generated Type 選 UV Grid 或 Color Grid，貼到物件上，格子是正方形就代表沒有拉伸
- 方法二：UV 編輯器右上角 Overlays › 勾選 Display Stretch，藍色代表沒拉伸、越紅拉伸越嚴重
格子大小不一致代表 UV 比例不一（Texel Density 不平均）。

## 整理 UV 島（UV Island、Pack Islands）
UV 編輯器中每一塊連在一起的 UV 叫做 UV 島（Island）。
- L：滑鼠移到島上按 L 選取整塊
- G / R / S：移動、旋轉、縮放 UV
- UV › Pack Islands：自動把所有島排緊、塞進 0～1 的範圍內，可以設 Margin（間距）避免貼圖滲色
- UV › Average Islands Scale：讓每塊 UV 的比例一致
- UV 要待在中間那個正方形範圍（0～1）裡面，超出的部分貼圖會重複

## 貼上圖片貼圖（Image Texture）
1. 切到 Shading 工作區
2. Shift + A › Texture › Image Texture
3. 按 Open 開啟圖片
4. 把 Color 輸出接到 Principled BSDF 的 Base Color
沒有展 UV 時貼圖可能會變形或變成一片純色。快捷方式：直接從檔案總管把圖片拖進 Shader Editor。

## 貼圖的色彩空間（sRGB、Non-Color）
Image Texture 節點下方的 Color Space 很重要：
- 顏色類貼圖（Base Color、Albedo、Diffuse）：sRGB
- 數據類貼圖（Roughness、Metallic、Normal、Displacement、AO）：Non-Color
數據貼圖設錯成 sRGB，粗糙度、凹凸效果會不正確（法線貼圖錯得最明顯）。

## PBR 貼圖有哪些（Base Color、Roughness、Normal…）
PBR（Physically Based Rendering）材質常見的貼圖：
- Base Color / Albedo：顏色（不含光影）→ 接 Base Color
- Roughness：粗糙度，白色粗糙、黑色光滑 → 接 Roughness（Non-Color）
- Metallic：金屬度，白色是金屬 → 接 Metallic（Non-Color）
- Normal：藍紫色的法線貼圖 → 經過 Normal Map 節點 → 接 Normal（Non-Color）
- Height / Displacement：高度黑白圖 → 經過 Bump 或 Displacement 節點
- AO（Ambient Occlusion）：縫隙陰影，Blender 通常不需要，可以用 Mix 乘到顏色上
- Glossiness / Specular：舊格式，Gloss 是 Roughness 的反相（用 Invert 節點轉換）
法線貼圖分 OpenGL 和 DirectX 兩種，Blender 用 OpenGL；DirectX 的要把綠色通道反相，凹凸才會正確。

## 調整貼圖大小、位置、重複（Mapping、Texture Coordinate）
Texture Coordinate（UV 輸出）› Mapping › Image Texture 的 Vector 輸入：
- Mapping 的 Scale：數字越大貼圖越小、重複越多次
- Location：位移；Rotation：旋轉
有 Node Wrangler 時選取 Image Texture 按 Ctrl + T 一鍵加好。
沒有 UV 的物件可以用 Image Texture 的投影方式 Box，搭配 Texture Coordinate 的 Object 或 Generated 輸出。

## 貼圖解析度與貼圖預算（Texture Resolution、2 的次方）
- 貼圖常用 512、1024（1K）、2048（2K）、4096（4K）這類 2 的次方尺寸，遊戲引擎和顯示卡處理最有效率
- 解析度越高越清楚，但檔案越大、記憶體（VRAM）用越多：4K 貼圖約是 2K 的 4 倍
- 貼圖預算：依物件在畫面中的大小分配解析度，鏡頭前的主角用高解析，遠處的背景小物用低解析
- 紋素密度（Texel Density）：每單位面積分到多少像素，同一個場景的物件盡量一致，畫面才不會有的清楚有的模糊

## 在模型上畫貼圖（Texture Paint）
1. 先展好 UV
2. 切到 Texture Paint 工作區（或模式選單選 Texture Paint）
3. 左側或上方的 Texture Slots 按 + 新增一張貼圖（Base Color）
4. 直接在模型上畫；F 調筆刷大小、Shift + F 調強度
重要：畫的貼圖不會自動存檔！要在 Image Editor 中 Image › Save（Alt + S）存成圖片，或用 Pack Resources 打包，不然關掉 Blender 就不見了。

## 烘焙貼圖（Bake、法線烘焙 Normal Bake）
烘焙是把材質、光影或高模細節「拍成」一張貼圖，常用在：遊戲用的低模、把程序化材質轉成圖片、高模細節轉法線貼圖。
基本流程（要用 Cycles）：
1. 低模展好 UV，材質中新增一個 Image Texture 節點並新建一張空白圖片，選取（點一下）這個節點
2. Render Properties › Render Engine 切 Cycles › Bake 面板選 Bake Type（Diffuse、Normal、Roughness、Combined…）
3. 高模轉低模的法線：先選高模，再 Shift 選低模，勾選 Selected to Active，調 Extrusion 或 Cage 讓光線涵蓋高模
4. 按 Bake，完成後到 Image Editor 存檔
烘焙出來全黑或破洞：檢查節點有沒有被選取、UV 是否重疊、Extrusion 是否太小、法線方向。
