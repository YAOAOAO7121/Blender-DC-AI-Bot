# 常見問題

## 模型有些面變黑、變暗或顏色怪怪的（法線反了）
開啟視窗右上角 Viewport Overlays 下拉選單中的 Face Orientation：藍色是正面、紅色是背面。
修正方法：進入編輯模式，A 全選，按 Shift + N（Recalculate Outside）讓法線統一朝外。

## 倒角、加厚、修改器效果不均勻
大多是物件縮放沒有套用。回到物件模式，選取物件按 Ctrl + A › Scale。

## 拉近視角時物件被切掉、或拉不近
- 被切掉：按 N 打開側邊欄 › View 分頁，把 Clip Start 改小一點（例如 0.01 m）
- 拉不近：視角中心離物件太遠，先選取物件按 Numpad . 讓視角對準它再縮放

## 檔案當掉沒存到
File › Recover › Recover Last Session 或 Auto Save，可以找回自動存檔。平常記得多按 Ctrl + S。

## 不小心按到什麼，畫面跟平常不一樣
- 先試 Ctrl + Z 復原
- 確認左上角是 Object Mode 還是 Edit Mode（Tab 切換）
- 確認沒有在區域視圖（再按一次 Numpad / 退出）
- 真的亂掉可以 File › Defaults › Load Factory Settings 恢復預設設定（會重設偏好設定，請先確認）
