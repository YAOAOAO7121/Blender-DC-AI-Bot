# 物件基本操作（物件模式 Object Mode）

## 新增與刪除物件
- Shift + A：新增物件（Mesh 裡有 Cube、UV Sphere、Cylinder 等基本形狀）
- 新增後左下角會出現一個小面板，可以調整尺寸、段數等參數；做了其他操作後面板就會消失
- X 或 Delete：刪除選取的物件

## 移動、旋轉、縮放物件（G / R / S，Move / Rotate / Scale）
- G 移動（Grab）、R 旋轉（Rotate）、S 縮放（Scale）
- 按完後移動滑鼠，左鍵或 Enter 確定，右鍵或 Esc 取消
- 再按 X / Y / Z：只沿著那個軸操作；連按兩次是沿著物件自己的軸
- Shift + X / Y / Z：鎖住那個軸，只在另外兩個軸操作（例如 S Shift+Z 是只縮放寬和深）
- 直接打數字：精準數值，例如 S 2 Enter 放大兩倍、R Z 90 Enter 繞 Z 軸轉 90 度
- 按住 Ctrl：吸附格線；按住 Shift：慢速微調

## 把移動、旋轉、縮放還原
- Alt + G：位置歸零
- Alt + R：旋轉歸零
- Alt + S：縮放回到 1

## 套用縮放（Ctrl + A › Apply Scale）
在物件模式縮放物件後，Blender 會記得「縮放比例不是 1」。這會讓倒角（Bevel）、厚度（Solidify）、UV、物理模擬等效果變形或不均勻。
解法：選取物件，按 Ctrl + A › Scale，把目前的大小「套用」成新的原始大小，縮放值會變回 1。
建議養成習慣：在物件模式縮放完、要開始做倒角或加修改器之前，先套用縮放。

## 複製物件
- Shift + D：複製一個獨立的物件，複製後可以直接移動，右鍵取消移動（但複製品仍會留在原地）
- Alt + D：關聯複製，網格共用，改其中一個另一個也會跟著變

## 隱藏、合併、分離
- H：隱藏選取的物件；Alt + H：顯示全部隱藏的物件
- Ctrl + J：把選取的多個物件合併成一個（最後選的那個是主體）
- 編輯模式中選取部分網格按 P › Selection：分離成獨立物件

## 原點（橘色小點）
原點是物件旋轉、縮放的中心。想改位置：在物件上按右鍵 › Set Origin，例如 Origin to Geometry（移到物件中心）、Origin to 3D Cursor（移到 3D 游標的位置）。
Shift + 右鍵 可以放置 3D 游標。

## 復原
- Ctrl + Z：復原；Ctrl + Shift + Z：重做
- Edit › Undo History：看操作紀錄，一次跳回比較早的步驟
