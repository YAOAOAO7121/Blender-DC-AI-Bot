# 幾何節點入門（Geometry Nodes）
<!-- 適用 Blender 4.x / 5.x -->

## 幾何節點是什麼（Geometry Nodes）
幾何節點用節點的方式「程序化」產生或修改模型，例如：在地面上隨機散佈石頭、草、樹；自動排列；做抽象動態造型。
優點：改參數就能重新產生、不破壞原始模型，可以做出大量變化。
5.0 以後內建了幾個用幾何節點做的修改器（例如 Scatter on Surface、Instance on Elements、Randomize Instances、新的 Array），直接從 Add Modifier 加入就能用，不必自己接節點。

## 開始使用幾何節點
1. 選取物件 › 上方切到 Geometry Nodes 工作區
2. 中間的節點編輯器按 New，物件會加上 Geometry Nodes 修改器
3. 預設有 Group Input（原始模型）→ Group Output（結果）
4. Shift + A 加節點，串在兩者中間

## 在表面上隨機散佈物件（Distribute Points、Instance on Points）
例如在地面上長滿石頭：
1. 地面物件加幾何節點
2. Group Input › Distribute Points on Faces（在表面撒點，Density 控制密度）
3. › Instance on Points（在每個點上放一個物件）
4. 把要散佈的物件從 Outliner 拖進節點編輯器（產生 Object Info 節點），Geometry 輸出接到 Instance on Points 的 Instance
5. 想保留地面本身：用 Join Geometry 把原始地面和散佈結果合併 › Group Output
用 Collection Info 節點（勾選 Separate Children、Pick Instance）可以從一個集合中隨機挑選不同物件。

## 隨機旋轉和大小（Random Value）
加 Random Value 節點：
- 類型改 Vector，接到 Instance on Points 的 Rotation，可以隨機旋轉（只想繞 Z 軸轉就把 X、Y 的範圍設 0）
- 類型 Float，接到 Scale，隨機大小（例如 Min 0.5、Max 1.5）
- 改 Seed 會產生不同的隨機結果

## 實例化與實體化（Instance、Realize Instances）
散佈出來的是「實例（Instance）」，記憶體用量很小，可以放幾萬個。
需要對結果做進一步修改（例如布林、套用材質變化）時，加 Realize Instances 節點轉成真正的網格，但會變重。

## 用雜訊讓表面起伏（Set Position、Noise Texture）
Set Position 節點的 Offset 接上 Noise Texture（經過 Vector Math 乘上法線方向或只用 Z），可以讓網格表面產生起伏（地形、流動造型）。
網格需要有足夠的面數。Noise 的 W 值或座標加上時間（用 #frame 驅動器或 Scene Time 節點）可以做出動態變化。

## 幾何節點的常見問題
- 物件看起來沒變化：檢查有沒有接到 Group Output、修改器的視窗顯示是否開啟
- 散佈的物件太大：被散佈的原始物件記得先套用縮放
- 想把結果變成一般網格：在修改器下拉選單 Apply
- 散佈的物件也出現在原位：把原始物件隱藏或放到被排除（Exclude）的集合裡
