# 介面、工作區與大綱（Workspace、Outliner、Properties）
<!-- 補充 01_介面與視角操作。適用 Blender 4.x / 5.x -->

## 上方的分頁是什麼（Workspaces 工作區）
最上方的 Layout、Modeling、Sculpting、UV Editing、Texture Paint、Shading、Animation、Rendering、Compositing、Geometry Nodes、Scripting 是「工作區」，每個工作區是預先排好的視窗配置，方便做不同的工作：
- Layout：預設綜合配置
- Modeling：建模
- Sculpting：雕刻
- UV Editing：展 UV
- Shading：調材質（含 Shader Editor）
- Animation：動畫（含 Dope Sheet）
- Compositing：合成
切換工作區不會改變你的模型，只是換一種畫面配置。上方的 + 可以新增工作區。

## 右上角的大綱是什麼（Outliner、集合 Collection）
Outliner 列出場景中所有的物件，像檔案總管：
- 點名稱選取物件；雙擊或 F2 改名
- 眼睛圖示：在視窗中隱藏／顯示（和 H 一樣）
- 相機圖示：渲染時是否出現（需要從漏斗圖示 Filter 開啟顯示）
- 集合（Collection）像資料夾，用來分類物件
- 集合前面的勾選框：排除（Exclude），取消勾選後整個集合從場景中排除
- 漏斗圖示（Filter）可以打開更多開關：選取鎖定（箭頭）、視窗停用（螢幕）

## 用集合整理物件（M 移到集合）
- 選取物件按 M › 選擇集合或 + New Collection：移動到集合
- 在 Outliner 拖曳物件到集合
- 集合上按右鍵 › Select Objects：選取整個集合的物件
- Ctrl + 點選集合的眼睛圖示：只顯示這個集合
建議依用途分類：Environment、Characters、Props、Lights、Cameras。

## 右下角的屬性面板（Properties 各圖示）
Properties 面板左側一排圖示由上到下大致是：
- Tool（工具設定）
- Render（渲染引擎、取樣）
- Output（解析度、幀率、輸出路徑與格式）
- View Layer（渲染通道 Passes）
- Scene（作用中攝影機、單位、重力）
- World（環境、背景、HDRI）
- Collection（集合設定）
- Object（物件位置、可見度、顯示方式）
- Modifiers（扳手：修改器）
- Particles（粒子）
- Physics（物理）
- Object Constraints（約束）
- Object Data（綠色三角形：網格資料、頂點群組、形狀鍵、UV；燈、攝影機、曲線也在這個位置）
- Material（材質）
- Texture（紋理）
選不同類型的物件，圖示會不一樣。

## 切換、分割視窗（Editor Type、Split Area）
- 每個區域左上角的下拉選單可以切換編輯器類型（3D Viewport、Shader Editor、Image Editor、Timeline 等）
- 把滑鼠移到區域的角落，游標變十字時拖曳：分割出新區域
- 在區域交界處右鍵 › Join Areas：合併區域
- Ctrl + Space：放大目前區域
- 不小心把畫面弄亂：重新切換工作區，或 File › New › General 開新檔案（舊檔記得存）

## 視窗顯示選項（Overlays、Viewport Shading、X-Ray）
3D 視窗右上角：
- Viewport Overlays（兩個交疊圓圈）：開關格線、統計資料 Statistics、法線方向 Face Orientation、線框等
- X-Ray（Alt + Z）：透視模式
- Viewport Shading 的下拉箭頭：Solid 模式可以改顏色顯示（Material、Object、Random、Texture）、光照方式（Studio、MatCap、Flat）
- Show Gizmo：開關畫面上的操作小工具
Random 顏色模式可以讓每個物件顯示不同顏色，方便分辨。

## 左上角的模式選單（Object、Edit、Sculpt…）
左上角的下拉選單切換模式：Object Mode、Edit Mode、Sculpt Mode、Vertex Paint、Weight Paint、Texture Paint。
- Tab：物件模式和編輯模式快速切換
- Ctrl + Tab：圓盤選單選擇模式（骨架則是切換 Pose 模式）
不同模式的快捷鍵和工具會不同，按了沒反應時先確認目前在哪個模式。

## 選取多個物件同時修改數值（Alt 拖曳、Copy to Selected）
- 選取多個物件後，在數值欄位按住 Alt 再拖曳或輸入，所有選取的物件會一起改
- 或改好作用中物件的數值後，在欄位上按右鍵 › Copy to Selected
- 修改器可以用修改器下拉選單 › Copy to Selected 複製給其他物件
- Ctrl + L › Copy Modifiers：把作用中物件的所有修改器複製給其他選取的物件

## 物件約束（Constraints）
約束可以限制或自動控制物件的變換，在 Object Constraint Properties 加入：
- Track To / Damped Track：一直朝向目標
- Copy Location / Rotation / Scale：複製另一個物件的位置、旋轉、大小
- Child Of：可以動畫切換的父子關係
- Follow Path：沿路徑移動
- Limit Location / Rotation：限制移動、旋轉範圍
- Floor：不能穿過地面
