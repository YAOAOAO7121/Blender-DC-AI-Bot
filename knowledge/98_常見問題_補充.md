# 常見問題（補充）

## 物件在視窗看得到，渲染出來卻不見
- Outliner 中物件的相機圖示（Disable in Renders）被關掉：點漏斗 Filter 打開相機圖示的顯示再檢查
- Object Properties › Visibility › Renderable 被取消
- 物件在攝影機的 Clip Start / End 範圍外
- 物件所在的集合被排除或渲染關閉
- 修改器的渲染開關（相機圖示）和視窗開關不同

## 材質在 Solid 模式看不到顏色
Solid 模式預設不顯示材質。切到 Material Preview（Z › Material Preview），或 Viewport Shading 下拉選單把 Color 改成 Material / Texture。

## 選不到物件、點了沒反應
- 物件被鎖定選取：Outliner 漏斗 Filter 打開箭頭圖示（Selectable），確認沒有被關掉
- 物件被其他東西擋住：Alt + Z 開 X 光，或在 Outliner 直接點名稱
- 在錯誤的模式（例如在另一個物件的編輯模式中），先 Tab 回物件模式
- 左鍵點選會選到最前面的物件，連點多次可以循環選到後面的物件

## 物件旋轉、縮放的中心點怪怪的
- 檢查物件原點（橘色小點）的位置，右鍵 › Set Origin › Origin to Geometry
- 檢查變換中心（按 . 句號叫出選單），一般用 Median Point
- 修改器（例如 Mirror）、對稱雕刻也是以原點為基準

## 鏡像（Mirror）後中間有裂縫或重疊
- 勾選 Mirror 修改器的 Clipping 和 Merge
- 中間的點要剛好在 X = 0（可以選取中間的點 S X 0 對齊，再把位置設為 0）
- 物件原點要在模型的中心線上

## 細分後形狀變得太圓、像麻糬（Subdivision 支撐線）
細分曲面會讓形狀往內收圓。想保持邊角：
- 在邊角附近加切線（Ctrl + R）當支撐線，越靠近邊角越銳利
- 或對邊做倒角（Ctrl + B，2～3 段）
- 或用 Shift + E 設定邊摺痕（Crease）

## 布林運算後模型破掉、出現奇怪的面
- 兩個物件都要是封閉的網格（沒有破洞）
- 法線方向要正確（Shift + N）
- 避免兩個面剛好完全重合，稍微移動一點點
- Solver 用 Exact（或 4.5 以後的 Manifold）
- 套用縮放（Ctrl + A）
- 布林後的面常有細長三角面，需要平滑著色時可以用 Auto Smooth 或整理佈線

## 畫面閃爍、兩個面互相穿插閃動（Z-fighting）
兩個面在同一個位置重疊時，會互相搶顯示而閃爍。
解法：把其中一個物件稍微移開、刪掉重複的面、或 M › By Distance 合併重疊點。

## 平滑著色後出現奇怪的黑影、條紋
- 有重疊的點：M › By Distance
- 法線反了：Shift + N
- 多邊面（N-gon）或細長三角面放在曲面上：重新整理佈線
- 需要銳利邊角的地方：右鍵 › Shade Auto Smooth，或 Mark Sharp

## 擠出（E）之後拉不動、形狀不對
- 擠出後右鍵取消，新的面還在原地（重疊），用 Ctrl + Z 或 M › By Distance 清掉
- 想沿法線方向擠出：Alt + E › Extrude Faces Along Normals
- 擠出被吸附影響：檢查磁鐵（Snapping）是否開啟

## 比例編輯（O）不小心開著，一動就拉一大片
畫面上方的同心圓圖示亮著代表比例編輯開啟，按 O 關掉。移動時滾輪可以調整影響範圍。

## 吸附（磁鐵）不小心開著，物件一直跳格
畫面上方的磁鐵圖示亮著代表吸附開啟，按 Shift + Tab 關掉，或移動時按住 Ctrl 暫時切換。

## 渲染的圖片存到哪裡了
- F12 渲染的單張圖不會自動存檔，要在渲染視窗 Image › Save As
- 動畫（Ctrl + F12）輸出到 Output Properties › Output 設定的路徑，預設是 /tmp\，Windows 會存在 C:\tmp\
- 建議改成自己的專案資料夾，路徑開頭的 // 代表和 .blend 檔同一個資料夾

## 介面不小心關掉、面板不見
- 側邊欄不見：滑鼠在 3D 視窗按 N
- 工具列不見：按 T
- 時間軸、Properties 不見：在任一區域左上角切換編輯器類型
- 整個版面亂掉：切換到其他工作區，或 File › New › General 開新檔案；開舊檔時取消勾選 Load UI 會套用目前的版面

## Eevee 和 Cycles 渲染出來不一樣
兩個引擎的計算方式不同，玻璃、陰影、間接光、自發光照明的效果會有差異。
- 決定好最終要用哪個引擎再精調燈光與材質
- Eevee 4.2 以後開啟 Raytracing 會比較接近 Cycles
- Shader to RGB 等節點只有 Eevee 支援

## 方塊或物件刪掉了怎麼找回
- 馬上 Ctrl + Z 復原
- 新增：Shift + A › Mesh › Cube
- 不見但沒刪除：可能被隱藏（Alt + H 顯示全部）、在區域視圖中（Numpad /）、或在被排除的集合

## 修改器數值改了沒變化
- 確認修改器的視窗顯示（螢幕圖示）是開著的
- 確認在 Object Mode 或修改器有開啟編輯模式顯示
- 修改器順序會影響結果
- 物件面數太少（例如 Displace、Simple Deform 需要足夠的切線）

## 匯入的模型很大或很小、看不到
- 按 Numpad .（或 Home）找到物件
- 選取 › S 縮放到合適大小 › Ctrl + A 套用縮放
- 太大時可能超出 Clip End：N › View 調大 Clip End
- FBX 從其他軟體來的常有 0.01 或 100 倍的比例差

## 想要教學影片或官方說明書
- Blender 官方手冊（有部分中文翻譯）：docs.blender.org/manual
- Blender 官方 YouTube 頻道與 Blender Studio 教學
- 問問題時說明 Blender 版本、附上截圖、說明做到哪一步，會更快得到正確答案
