# 檔案管理與匯入匯出（Save、Import、Export）
<!-- 適用 Blender 4.x / 5.x -->

## 存檔、另存新檔、備份檔（Ctrl + S、.blend1）
- Ctrl + S：存檔；Ctrl + Shift + S：另存新檔
- 另存時檔名旁的 + / - 按鈕：自動在檔名加版本號（project_01、project_02）
- 存檔後資料夾裡的 .blend1 是上一次的存檔備份，改副檔名成 .blend 就能打開
- 自動存檔：Edit › Preferences › Save & Load › Auto Save（預設每 2 分鐘），找回：File › Recover › Auto Save
- 建議重要階段另存新版本，不要一直覆蓋同一個檔案

## 檔案傳給別人貼圖不見（Pack Resources、打包）
.blend 檔預設只記錄貼圖的路徑，圖片本身不在檔案裡，傳給別人或換電腦就會變粉紅色。
交檔前：File › External Data › Pack Resources，把圖片打包進 .blend 檔（檔案會變大）。
- Unpack Resources：把打包的圖片解開到資料夾
- Make Paths Relative：路徑改成相對路徑，整個資料夾一起搬移不會斷
- Find Missing Files：指定資料夾讓 Blender 重新找貼圖
建議：把專案的 .blend 和貼圖放在同一個資料夾，整個資料夾壓縮傳送。

## 從別的 Blender 檔案拿物件或材質（Append、Link）
File › Append：選另一個 .blend 檔 › 進入 Object（或 Material、Collection 等）資料夾 › 選要的東西 › Append。
- Append：複製一份到目前檔案，可以自由修改
- Link：只是引用，原檔改了這邊會跟著更新，但這邊不能直接修改（適合團隊共用場景、角色）

## 常用 3D 檔案格式差在哪（FBX、OBJ、glTF、STL、USD）
- FBX：遊戲引擎（Unity、Unreal）、Mixamo 最常用，可以包含骨架與動畫
- OBJ：最古老通用的格式，只有模型和簡單材質，沒有動畫
- glTF / GLB：網頁、AR、AI 生成 3D 模型最常用，GLB 是單一檔案（模型＋貼圖），材質是 PBR，推薦
- STL：3D 列印用，只有形狀沒有顏色
- USD / USDZ：大型製作流程與 Apple AR 使用
- PLY：點雲、掃描資料，部分 3DGS 結果也是 .ply（需要外掛才能正確顯示）
- Alembic（.abc）：烘焙好的動畫快取，跨軟體傳遞變形動畫
匯入：File › Import；匯出：File › Export。

## 匯出時要注意的設定（Selected Only、Apply Modifiers、Scale）
- Limit to › Selected Objects：只匯出選取的物件
- Apply Modifiers：套用修改器後輸出
- 匯出前先套用變換：Ctrl + A › All Transforms
- 方向：Blender Z 軸朝上，Unity / glTF 是 Y 軸朝上，FBX、glTF 匯出器預設會自動轉換（Forward / Up 選項）
- 匯出到 Unity 尺寸不對：FBX 匯出 Transform › Apply Scalings 選 FBX All，或在 Unity 調 Scale Factor
- 貼圖要一起帶走：FBX 的 Path Mode 選 Copy 並按旁邊的打包按鈕（Embed Textures），或改用 GLB

## 匯入照片當平面（Images as Planes）
把圖片直接變成一個有材質、比例正確的平面，做參考圖、背景、卡片很方便：
- 4.2 以後：Shift + A › Image › Mesh Plane（已內建）
- 4.1 以前：需要在 Preferences › Add-ons 啟用 Import Images as Planes，再從 File › Import 使用

## 放參考圖（Reference Image、建模底圖）
Shift + A › Image › Reference：在 3D 空間放一張參考圖（只在視窗顯示、不會被渲染）。
Shift + A › Image › Background：放在背後的參考圖。
先切到前視圖（Numpad 1）或側視圖（Numpad 3）再新增，圖片會正對著視角。可以在物件屬性調整透明度（Opacity）。

## 素材庫（Asset Browser、拖曳使用）
把常用的物件、材質標記成資產（右鍵 › Mark as Asset），之後在 Asset Browser 直接拖曳到場景。
Edit › Preferences › File Paths › Asset Libraries 可以新增自己的素材庫資料夾。
4.x 以後也內建了一些官方資產（例如人體基礎模型、筆刷、幾何節點工具）。

## 新版檔案用舊版打不開或怪怪的（版本相容）
- 舊版做的檔案用新版打開通常沒問題
- 新版做的檔案用舊版打開，可能缺少功能、材質錯誤或打不開
- 同組同學、課堂作業盡量用同一個版本
- Blender 4.2 LTS、4.5 LTS 是長期支援版，比較穩定；版本以老師指定為準

## 中文路徑、中文檔名會出問題嗎
大部分情況 Blender 可以處理中文檔名與資料夾，但某些外掛、匯出器、算圖農場或其他軟體可能讀不到。
保險做法：專案資料夾、貼圖檔名使用英文和數字，不要有空格和特殊符號（例如 chair_wood_01.png）。
