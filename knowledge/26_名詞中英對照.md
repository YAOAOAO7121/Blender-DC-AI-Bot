# 名詞中英對照（Glossary）
<!-- 讓學生用中文或英文問都找得到。中文名稱各教材不完全一致，括號內是常見的其他說法 -->

## 介面與操作名詞
- Viewport：視窗、3D 視圖
- Outliner：大綱、大綱視圖
- Properties：屬性面板
- Workspace：工作區
- Object Mode / Edit Mode：物件模式 / 編輯模式
- Sculpt Mode：雕刻模式
- Pose Mode：姿勢模式
- 3D Cursor：3D 游標
- Origin：原點（物件中心）
- Pivot Point：變換中心、樞紐點
- Gizmo：操作小工具、控制器
- Overlay：覆蓋層、疊加顯示
- Snapping：吸附
- Proportional Editing：比例編輯、衰減編輯、軟選取
- Transform：變換（移動 Move / Grab、旋轉 Rotate、縮放 Scale）
- Apply：套用
- Collection：集合
- Local View：區域視圖

## 建模名詞
- Mesh：網格
- Vertex / Edge / Face：點（頂點）/ 邊（線）/ 面
- Polygon：多邊形；Quad：四邊面；Tri：三角面；N-gon：多邊面
- Topology：拓樸；Edge Flow：佈線
- Normal：法線
- Extrude：擠出（長面）
- Inset：內插面
- Bevel：倒角
- Loop Cut：環切（切線）
- Knife：刀具
- Merge：合併；Dissolve：溶解
- Bridge：橋接
- Subdivide：細分
- Boolean：布林（Union 聯集、Intersect 交集、Difference 差集）
- Modifier：修改器（編修器）
- Subdivision Surface：細分曲面
- Mirror：鏡像；Array：陣列；Solidify：加厚
- Decimate：減面
- Remesh：重建網格
- Retopology：重新拓樸
- Manifold：封閉網格（流形）；Non-manifold：非封閉、有破洞的網格
- Shade Smooth / Flat：平滑著色 / 平面著色
- Primitive：基本幾何體
- Low Poly / High Poly：低模 / 高模

## 材質與貼圖名詞
- Material：材質
- Shader：著色器
- Node：節點
- Principled BSDF：原理化 BSDF（萬用材質）
- Base Color / Albedo / Diffuse：基本色、底色、漫射色
- Roughness：粗糙度；Metallic：金屬度
- Specular：反射、高光
- IOR（Index of Refraction）：折射率
- Transmission：透射；Subsurface Scattering（SSS）：次表面散射
- Emission：自發光
- Alpha：透明度
- Texture：紋理、貼圖
- Procedural Texture：程序化紋理
- UV / UV Unwrap：UV / UV 展開
- Seam：接縫
- UV Island：UV 島
- Normal Map：法線貼圖；Bump：凹凸；Displacement：置換
- PBR（Physically Based Rendering）：基於物理的渲染
- Bake：烘焙
- Texel Density：紋素密度
- HDRI：高動態範圍環境圖

## 打光、攝影機與渲染名詞
- Light：燈光（Point 點光、Sun 太陽光、Spot 聚光燈、Area 面光）
- Key / Fill / Rim Light：主光 / 補光 / 輪廓光
- World：世界（環境）
- Render：渲染（算繪、算圖）
- Render Engine：渲染引擎（Eevee、Cycles、Workbench）
- Samples：取樣數
- Denoise：降噪
- Noise：雜訊、噪點
- Firefly：亮點雜訊
- Ray Tracing / Path Tracing：光線追蹤 / 路徑追蹤
- Global Illumination：全域照明、間接光
- Ambient Occlusion（AO）：環境光遮蔽
- Focal Length：焦距
- Depth of Field（DOF）：景深
- Aperture / F-Stop：光圈
- Resolution：解析度
- Aspect Ratio：畫面比例
- Color Management：色彩管理
- View Transform：視圖轉換（AgX、Filmic、Standard）
- Exposure：曝光
- Compositor / Compositing：合成器 / 合成
- Render Pass：渲染通道
- Video Sequencer（VSE）：影片編輯器（序列編輯器）
- Frame Rate（fps）：幀率（影格率）
- Codec：編碼器；Container：容器格式；Bitrate：位元率

## 動畫與綁定名詞
- Keyframe：關鍵影格（關鍵幀）
- Timeline：時間軸
- Dope Sheet：攝影表、動畫表
- Graph Editor：曲線編輯器
- F-Curve：動畫曲線
- Interpolation：補間、插值
- Ease In / Ease Out：緩入 / 緩出
- Extrapolation：外插
- Action：動作
- NLA（Nonlinear Animation）：非線性動畫
- Shape Key：形狀鍵（變形鍵、Blend Shape）
- Armature：骨架
- Bone：骨頭
- Rigging：綁定（骨架綁定）
- Skinning：蒙皮
- Weight Paint：權重繪製
- Vertex Group：頂點群組
- IK（Inverse Kinematics）/ FK（Forward Kinematics）：反向動力學 / 正向動力學
- Constraint：約束
- Parent / Child：父物件 / 子物件
- Driver：驅動器
- Retargeting：動作重定向
- Motion Capture（MoCap）：動作捕捉

## 模擬與其他名詞
- Rigid Body：剛體
- Soft Body：柔體
- Cloth：布料
- Fluid：流體
- Particle：粒子
- Force Field：力場
- Cache / Bake：快取 / 烘焙
- Geometry Nodes：幾何節點
- Instance：實例
- Add-on / Extension：外掛 / 擴充功能
- Photogrammetry：攝影測量
- 3D Gaussian Splatting（3DGS）：3D 高斯潑濺
- Point Cloud：點雲
- Structure from Motion（SfM）：運動恢復結構
