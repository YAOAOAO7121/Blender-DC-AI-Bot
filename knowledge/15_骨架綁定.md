# 骨架與角色綁定（Armature、Rigging）
<!-- 對應課程第 9 週「角色綁定與動作設計；AI 輔助動作生成工具」。適用 Blender 4.x / 5.x -->

## 綁定是什麼（Rigging、骨架 Armature）
綁定是幫模型裝上「骨架」，讓模型可以像玩偶一樣擺姿勢和做動畫。
流程：建立骨架 → 把模型綁到骨架（設定權重）→ 加上控制器（IK 等）→ 在 Pose 模式做動畫。

## 新增骨架、長骨頭（Add Armature、E 擠出骨頭）
1. Shift + A › Armature：新增一根骨頭
2. Tab 進入骨架的編輯模式
3. 選取骨頭的尾端（Tip）按 E：擠出下一根骨頭，連成骨鏈
4. Shift + D 複製骨頭，Alt + P 斷開父子關係
- 骨頭被模型擋住看不到：Object Data Properties（骨頭圖示）› Viewport Display › 勾選 In Front
- 顯示骨頭名稱：Viewport Display › 勾選 Names
骨頭的位置通常放在關節處（肩膀、手肘、手腕、膝蓋）。

## 骨頭命名與左右對稱（.L、.R、Symmetrize）
- 左右對稱的骨頭命名結尾加 .L / .R（例如 upper_arm.L、upper_arm.R），Blender 才認得對稱
- 先做好左半邊的骨頭並命名 .L，選取後 Armature › Symmetrize 自動產生右半邊
- 編輯模式勾選右上角 X-Axis Mirror，一邊擠出另一邊也會一起長
- F2 或在 Outliner 雙擊可以改名

## 把模型綁到骨架（Ctrl + P › With Automatic Weights）
1. 物件模式下，先選模型，再 Shift 選骨架（骨架最後選）
2. Ctrl + P › With Automatic Weights（自動權重）
3. 選取骨架 › Ctrl + Tab 進入 Pose 模式，旋轉骨頭測試模型有沒有跟著動
綁定前記得：模型和骨架都套用縮放和旋轉（Ctrl + A › All Transforms）。

## 自動權重失敗（Bone Heat Weighting: failed）
出現「Bone Heat Weighting: failed to find solution for one or more bones」時，常見原因與解法：
- 模型有重疊的點：編輯模式 A 全選 › M › By Distance
- 模型由很多分開的零件組成、或有內部面：分開處理或清理
- 縮放太小或太大：套用縮放（Ctrl + A），或暫時把模型和骨架一起放大後綁定
- 法線方向錯誤：Shift + N
- 有些骨頭完全沒有在模型裡面

## 權重繪製（Weight Paint）
權重決定每根骨頭影響模型的哪些部分：紅色 = 完全影響（1）、藍色 = 不影響（0）。
1. 先選骨架，再選模型 › 切到 Weight Paint 模式
2. Ctrl + 左鍵點骨頭：選擇要編輯哪根骨頭的權重（也可以在 Object Data › Vertex Groups 選）
3. 用筆刷塗：Weight 1 是加、Weight 0 或 Subtract 是減；F 調大小
4. Blur 筆刷：讓關節處的權重平滑過渡
常見問題：動手臂時身體也被拉走 → 把身體上那根手臂骨頭的權重塗掉（Weight 0）。

## Pose 模式擺姿勢（Pose Mode、Ctrl + Tab）
- 選取骨架 › Ctrl + Tab 進入 Pose 模式，R 旋轉骨頭擺姿勢
- 打關鍵影格：選取骨頭 › I
- Alt + G / Alt + R / Alt + S：骨頭的位置、旋轉、縮放歸零（回到原始姿勢）
- 骨架 Object Data › Pose Position / Rest Position：切換姿勢與原始姿勢對照
- Ctrl + C / Ctrl + Shift + V：複製姿勢、鏡像貼上到另一側

## 反向動力學（IK、Inverse Kinematics）
一般骨頭是「正向動力學（FK）」：轉肩膀 → 手肘 → 手腕，一根根轉。
IK 是反過來：移動手腕（或腳），手肘、肩膀自動彎曲跟著，適合腳踩地、手扶東西。
做法：Pose 模式選取小腿骨 › Bone Constraint Properties › Add Bone Constraint › Inverse Kinematics：
- Target：選骨架並指定一根控制骨頭（腳的控制器，不要跟腿連在一起）
- Chain Length：影響幾根骨頭（腿通常是 2）
- Pole Target：膝蓋朝向的控制器，避免膝蓋亂轉
快捷方式：Shift + I 為選取的骨頭加 IK。

## 骨頭軸向扭轉（Bone Roll）
骨頭的 Roll 決定它繞自己軸線的方向，影響旋轉時的軸向和對稱。
編輯模式選取骨頭 › Shift + N › Recalculate Roll 可以統一方向；N 面板也可以手動設定 Roll。

## 自動綁定工具 Rigify（內建外掛）
Rigify 可以自動產生完整的角色控制器：
1. Edit › Preferences › Add-ons 啟用 Rigify
2. Shift + A › Armature › Human (Meta-Rig) 新增人型骨架範本
3. 進入編輯模式，把骨頭對齊到你的角色（只調左半邊，再用 Symmetrize）
4. 骨架 Object Data Properties › Generate Rig 產生正式的控制器骨架
5. 模型綁到產生的 rig（Ctrl + P › With Automatic Weights）

## Mixamo 自動綁定與現成動作
Adobe Mixamo（mixamo.com）可以免費自動綁定人型角色、套用大量現成動作：
1. 在 Blender 匯出模型（File › Export › FBX，Selected Objects、只輸出模型）
2. 上傳到 Mixamo，依指示標記下巴、手腕、手肘、膝蓋、胯下
3. 選動作 › Download（Format FBX、With Skin）
4. 回 Blender › File › Import › FBX
人型、T-pose 或 A-pose、手腳分開的角色效果最好；四足動物、多肢角色不適用。服務內容可能會改變，以網站實際狀況為準。

## AI 輔助動作生成工具（影片轉動作、文字生成動作）
現在有很多 AI 工具可以從一般影片抓出人體動作（不需要動態捕捉服），或用文字描述生成動作，輸出 FBX / BVH 匯入 Blender：
- 影片轉動作（Video to Motion Capture）：例如 Rokoko Vision、DeepMotion、Move AI、Plask 等
- 文字生成動作（Text to Motion）：部分平台提供輸入文字描述產生動作
使用要點：
- 拍攝時全身入鏡、背景單純、光線充足、衣服不要太寬鬆
- 匯入後常見問題：腳滑步（Foot Sliding）、手指和腳穿透地面、抖動，需要在 Graph Editor 修整或減少關鍵影格
- 把抓到的動作套到自己的角色上叫「重定向（Retargeting）」，骨架名稱和比例不同時需要對應
工具更新很快，免費額度與匯出格式各家不同，實際使用的工具以老師課堂介紹為準。

## 物件綁到骨頭上（拿武器、戴帽子 Bone Parent）
讓道具跟著某根骨頭動：
1. 物件模式選道具 › Shift 選骨架 › Ctrl + Tab 進入 Pose 模式 › 點選手部骨頭
2. Ctrl + P › Bone
或給道具加 Child Of 約束，Target 選骨架並指定骨頭（可以動畫開關，適合拿起放下）。
