# 影音知識與色彩管理（格式、幀率、壓縮、色彩）
<!-- 對應課程第 6 週「渲染影音知識：格式、色彩管理、幀率與壓縮」。適用 Blender 4.x / 5.x -->

## 幀率是什麼、要選多少（Frame Rate、FPS）
幀率是每秒播放幾張畫面（Frames Per Second）。Output Properties › Format › Frame Rate：
- 24 fps：電影、動畫最常用，有「電影感」
- 25 fps：歐洲 PAL 地區電視
- 30 fps（29.97）：台灣、美國、日本等 NTSC 地區的電視和網路影片
- 60 fps：遊戲畫面、運動、流暢的 UI 動畫
同一個作品要固定一個幀率；動畫做到一半才改幀率，動作的速度會變。
幀數換算時間：10 秒 × 24 fps = 240 格。

## 影片的長度、開始和結束格（Frame Range）
Output Properties › Frame Range 的 Frame Start、End，或時間軸（Timeline）右邊的 Start、End。
預設是 1～250 格。Step 設 2 代表每隔一格渲染一張（測試用）。

## 影片格式和編碼的差別（Container、Codec）
- 容器（Container）：檔案的外殼，例如 MP4、MOV、MKV、AVI
- 編碼（Codec）：畫面壓縮的方法，例如 H.264、H.265（HEVC）、ProRes、AV1
同樣是 .mp4，裡面可以是不同的編碼。最通用的組合：MP4 容器 ＋ H.264 編碼 ＋ AAC 音訊，幾乎所有裝置和社群平台都能播。

## Blender 怎麼直接輸出 MP4（FFmpeg Video、H.264）
Output Properties › Output：
1. File Format 選 FFmpeg Video
2. Encoding › Container 選 MPEG-4
3. Video › Video Codec 選 H.264
4. Output Quality 選 High Quality 或 Perceptually Lossless（數字品質越高檔案越大）
5. 有聲音的話 Audio › Audio Codec 選 AAC
6. Ctrl + F12 渲染動畫
新版本有內建的預設選項，可以直接在 Encoding 右側的預設清單選「H264 in MP4」。

## 為什麼建議先輸出圖片序列（PNG Sequence）
- 渲染中途當機或關機，已經算好的圖都還在，可以從斷掉的地方繼續
- 每張都是無壓縮或無損品質，後製調色空間比較大
- 最後在 Blender 影片編輯器或剪輯軟體匯入整個序列轉成影片
缺點是檔案數量多、佔空間。需要後製合成時可以用 OpenEXR（32 bit，保留最多資訊）。

## 圖片格式怎麼選（PNG、JPG、EXR、色彩深度）
- PNG：無損壓縮、支援透明（RGBA），最常用，8 bit 或 16 bit
- JPEG：有損壓縮、檔案小、不支援透明，適合最終分享
- OpenEXR：32 bit 浮點數、保留超亮的光線資訊與多個渲染通道，適合合成與調色
- TIFF：印刷、無損
- WebP：網頁用，檔案小
色彩深度（Color Depth）：8 bit 每個顏色 256 階，漸層可能出現色階斷層（Banding）；16 bit 有 65536 階，漸層平滑、後製空間大。

## 壓縮與檔案大小（Bitrate、位元率）
影片大小主要由位元率（Bitrate，每秒用多少資料）決定：檔案大小 ≈ 位元率 × 時間。
- 1080p 網路影片常見約 8～16 Mbps，4K 約 35～50 Mbps
- 畫面變化大、細節多（雜訊、粒子、樹葉）需要更高位元率，否則會出現馬賽克
- Blender 的 Output Quality 用品質（CRF）控制，也可以改成 Constant Bitrate 自己設定
- Encoding Speed：越慢壓得越好（同品質檔案較小）
渲染有雜訊時，壓縮後會更糊；先降噪再輸出。

## 色彩管理是什麼（Color Management、View Transform）
Render Properties › Color Management 控制「算出來的光」怎麼轉換成螢幕上的顏色：
- Display Device：通常是 sRGB（一般螢幕）
- View Transform：
  - AgX（4.0 以後預設）：能處理很亮的光，高光不會死白、飽和的顏色會自然地轉白，畫面比較像攝影
  - Filmic（4.0 以前的預設）：和 AgX 類似的舊版本
  - Standard：不做轉換，顏色和你設定的數值完全一樣，適合 UI 設計、品牌色、平面插畫、卡通風格
- Look：對比度（例如 AgX 的 Punchy、High Contrast）
- Exposure：曝光，整體亮度；Gamma：中間調
重要：同一個場景在 AgX 和 Standard 下顏色看起來不一樣。品牌色、指定色碼要準確時，用 Standard。

## 顏色看起來灰灰的、不飽和（AgX）
AgX 為了保留亮部細節，畫面會比 Standard 灰一點、飽和度低一點，這是正常的。
可以：Look 選 Punchy 或 High Contrast、在合成器加 Color Balance / Curves 調色、或改用 Standard。

## 線性色彩與 sRGB（Linear、Gamma）
Blender 內部用線性（Linear）的方式計算光線，比較符合物理；螢幕顯示時才轉成 sRGB。
所以：顏色貼圖用 sRGB、數據貼圖（粗糙度、法線）用 Non-Color，Blender 才會正確轉換。
5.0 以後可以把檔案的工作色彩空間（Working Color Space）改成 ACEScg（預設仍是 Linear Rec.709），並支援 HDR 影片輸出（Rec.2100 PQ / HLG）與廣色域（Display P3、Rec.2020）。初學者維持預設即可。

## 解析度常見規格（1080p、4K、直式短影音）
- 720p：1280 × 720
- 1080p（Full HD）：1920 × 1080
- 2K（DCI）：2048 × 1080；1440p：2560 × 1440
- 4K（UHD）：3840 × 2160
- 直式短影音：1080 × 1920（9:16）
- Instagram 貼文：1080 × 1080（1:1）或 1080 × 1350（4:5）
解析度加倍，渲染時間大約變成 4 倍。

## 聲音和影片不同步、播放速度不對
- Timeline › Playback › Sync 選 Sync to Audio：播放時會跳格以跟上聲音（預覽動作節奏時用）
- Play Every Frame：每一格都播但可能變慢
- 匯入影片的幀率和專案幀率不同時，影片長度和聲音會對不上：在影片編輯器選取影片 › Strip › Movie Strip › Set Render Size 或把專案幀率改成和影片一樣
