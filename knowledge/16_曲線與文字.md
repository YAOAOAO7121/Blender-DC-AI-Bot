# 曲線與 3D 文字（Curve、Text）
<!-- 適用 Blender 4.x / 5.x -->

## 新增曲線、編輯曲線（Bezier Curve）
- Shift + A › Curve › Bezier（貝茲曲線）、Circle、Path 等
- Tab 進入編輯模式：選取控制點 G 移動，兩側的把手控制彎曲程度
- E：從端點延伸新的點
- 選取兩個端點按 F：連接；Alt + C：讓曲線頭尾閉合（Toggle Cyclic）
- V：切換把手類型（Automatic、Vector 尖角、Aligned、Free）
- 右鍵 › Subdivide：在兩點之間加點

## 讓曲線變成管子、有厚度（Bevel Depth、Extrude）
曲線 Object Data Properties（綠色曲線圖示）› Geometry：
- Extrude：把曲線往上下拉成一片帶狀
- Bevel › Depth：讓曲線變成圓管，Resolution 增加圓滑度（做電線、水管、繩子）
- Bevel › Object：用另一條曲線當截面形狀（例如星形截面）
- Fill Caps：管子兩端封口
- Taper Object：用另一條曲線控制粗細變化（做觸手、樹枝）
曲線本身的 Resolution Preview U 控制曲線的平滑度。

## 曲線轉成網格（Convert to Mesh）
物件模式選取曲線 › 右鍵或 Object › Convert › Mesh，就變成可以用編輯模式點線面修改的網格。
轉換後無法再用曲線方式編輯，建議先複製一份備份。網格也可以反過來轉成曲線（Convert › Curve）。

## 匯入 SVG 向量圖（Illustrator、Logo）
File › Import › Scalable Vector Graphics (.svg)，SVG 會變成曲線物件。
- 匯入後通常非常小，要放大（S）並套用縮放
- 在曲線 Geometry › Extrude 給厚度，就變成立體 Logo
- 需要更多修改時轉成網格

## 新增 3D 文字（Text、Tab 編輯）
1. Shift + A › Text
2. Tab 進入編輯模式，Backspace 刪掉「Text」再打字
3. Tab 回物件模式
文字 Object Data Properties（a 圖示）：
- Geometry › Extrude：厚度；Bevel › Depth：邊緣圓角
- Paragraph › Alignment：對齊方式；Spacing：字距、行距
- Font：更換字型

## 3D 文字打中文變成方框（中文字型）
Blender 預設的字型沒有中文字，所以中文會變成方框或空白。
1. 文字 Object Data Properties › Font › Regular 旁的資料夾圖示
2. 選擇有中文的字型檔（.ttf / .otf），例如 Windows 的 C:\Windows\Fonts 裡的微軟正黑體，或免費的 Noto Sans TC（思源黑體）
3. 粗體、斜體各有欄位，也要指定中文字型
如果輸入法打字不穩：先在記事本打好文字複製，進入文字編輯模式按 Ctrl + V 貼上。
商業用途要注意字型授權，Google Fonts 上的 Noto 系列、jf open 粉圓等可以免費商用。

## 文字沿著曲線排列
文字 Object Data Properties › Shape › Text on Curve › 選一條曲線，文字就會沿曲線排列（例如做成圓形 Logo）。

## 文字轉網格（做更多造型）
選取文字 › Object › Convert › Mesh，文字就變成網格，可以加修改器、做布林、雕刻。
轉換後無法再修改文字內容。轉出的網格常有很多細長三角面，需要倒角時可以先 Remesh 或手動整理。
