# 後製與合成（Compositor、影片剪輯 Video Sequencer）
<!-- 對應課程「後製與合成：剪輯、調色、音軌與成品輸出」。適用 Blender 4.x / 5.x -->

## 合成器是什麼、怎麼開始（Compositor、Use Nodes）
合成器可以在渲染後自動做調色、光暈、景深、去背合成等後製。
1. 上方切到 Compositing 工作區
2. 4.x：勾選 Use Nodes；5.0 以後：按 New 新增一個合成節點群組
3. 預設會有 Render Layers（渲染結果）接到輸出節點：4.x 是 Composite 節點、5.0 以後是 Group Output 節點
4. 加入其他節點（Shift + A）串在中間
合成效果要渲染（F12）後才會套用到結果；4.x 以後也可以在 Viewport Shading 下拉選單把 Compositor 設為 Always，在視窗中即時預覽。

## 合成器怎麼預覽（Viewer 節點、Backdrop）
- 加一個 Viewer 節點（有 Node Wrangler 時 Ctrl + Shift + 左鍵點節點會自動接上）
- 合成器右上角按 Backdrop，節點背景就會顯示畫面
- V / Alt + V：縮放背景圖；Alt + 中鍵：移動背景圖

## 光暈、發光效果（Glare 節點、Bloom）
Render Layers › Glare › 輸出節點：
- Type：Bloom（柔和光暈，4.2 以後取代 Eevee 的 Bloom）、Fog Glow（霧狀光暈）、Streaks（星芒條紋）、Ghosts（鏡頭鬼影）
- Threshold：多亮的地方才發光，數值越低發光範圍越大
- Strength / Size：強度和範圍
搭配材質的 Emission，可以做出霓虹燈、科幻發光效果。

## 合成器調色（Color Balance、RGB Curves、Hue Saturation）
- Color Balance：Lift（暗部）、Gamma（中間調）、Gain（亮部）分別調顏色，例如亮部偏暖、暗部偏冷
- RGB Curves：曲線調整對比，拉成 S 形對比變強
- Hue / Saturation / Value：色相、飽和度、明度
- Brightness / Contrast：亮度、對比
- Exposure：曝光
5.0 以後內建了暈影（Vignette）、色差（Chromatic Aberration）等現成效果資產，可以從節點的 Asset 選單加入。

## 渲染通道（Render Passes、Mist、AO、Cryptomatte）
View Layer Properties（相片疊圖示）› Passes 可以勾選額外輸出：
- Z / Mist：深度，可以做霧氣、景深效果（Mist 範圍在 World › Mist Pass 設定）
- Ambient Occlusion：縫隙陰影
- Diffuse、Glossy、Emission：分別調整漫射、反射、發光
- Cryptomatte：自動依物件或材質產生遮罩，方便只調某個物件的顏色
勾選後 Render Layers 節點會多出這些輸出接口。

## 把渲染結果疊在背景圖或影片上（Alpha Over）
1. Film › Transparent 勾選，讓渲染背景透明
2. 合成器加 Image 節點（背景圖或影片）
3. Alpha Over 節點：上面接背景、下面接 Render Layers 的 Image
需要陰影落在背景的地面上：在地面物件 Object Properties › Visibility 勾選 Shadow Catcher（Cycles），地面會變透明只留陰影。

## 影片編輯器在哪裡（Video Sequencer、剪輯）
Blender 也可以剪片：
- File › New › Video Editing 開新的剪輯專案，或把任一區域切換成 Video Sequencer
- 開新專案前先設定好解析度和幀率（Output Properties）
- 長片或需要大量調色時，也可以用 DaVinci Resolve（免費版）、Premiere、CapCut 等專門剪輯軟體

## 匯入影片、圖片、聲音（Add Movie、Image Sequence、Sound）
- Shift + A › Movie：影片（會同時帶入聲音）
- Shift + A › Image/Sequence：圖片，選取資料夾內所有圖片（A 全選）就會變成一段序列
- Shift + A › Sound：音樂、音效
- Shift + A › Text：文字；Color：純色畫面
- Shift + A › Scene：把 3D 場景直接放進剪輯（不用先渲染）
也可以從檔案總管把檔案拖進來。匯入影片後若解析度或幀率不一致，選取影片 › 右鍵 Movie Strip › Set Render Size，或把專案改成和影片一樣的幀率。

## 剪開、刪除、移動片段（K、Shift + K、G、X）
- 把播放頭（藍色線）移到要剪的地方 › 選取片段按 K：剪開（Soft Split）
- Shift + K：硬切（Hard Split）
- G：移動片段；拖曳片段的頭尾：修剪長度
- X 或 Delete：刪除片段
- Shift + D：複製片段
- Ctrl + 左鍵拖曳時間軸：上下為軌道（Channel），上面的軌道會蓋住下面的
- 刪掉中間片段留下空隙：滑鼠在空隙按 Backspace（或 Strip › Gap Remove）可以把後面的片段往前補

## 轉場、淡入淡出（Cross、Fade）
- 交叉淡化：選取兩個有重疊的片段（在不同軌道）› Shift + A › Transition › Cross
- 淡入淡出：選取片段 › Add › Fade › Fade In / Fade Out / In and Out（會自動在透明度或音量打關鍵影格）
- 也可以自己在片段的 Opacity（不透明度）或 Volume（音量）上按 I 打關鍵影格

## 調整聲音音量、音軌（Volume、Waveform）
- 選取聲音片段 › 右側 N 面板 › Sound › Volume 調整音量
- 在 Volume 上按 I 打關鍵影格，可以讓音樂漸強漸弱、在說話時降低背景音樂
- View › Waveform 或片段設定勾選 Display Waveform 顯示波形，方便對拍子
- 輸出影片時記得 Audio Codec 選 AAC，否則影片會沒有聲音

## 剪輯中調色（Strip Modifiers）
選取影片片段 › 右側 N 面板 › Modifiers › Add Modifier：Color Balance、Curves、Hue Correct、Brightness/Contrast 等。
5.0 以後還可以在片段上加 Compositor 修改器，直接套用合成器的節點效果。

## 剪輯預覽很卡（Proxy、代理檔）
選取影片片段 › N 面板 › Proxy & Timecode › 勾選 Strip Proxy 並選 25% 或 50% › Set Selected Strip Proxies › Rebuild Proxy。
預覽視窗的 Proxy Render Size 設成同樣的比例，播放會順很多，輸出時仍用原始品質。

## 輸出成品影片（剪輯完成怎麼匯出）
1. Output Properties：確認解析度 100%、Frame Start / End 涵蓋整段剪輯
2. File Format：FFmpeg Video › Container MPEG-4 › Codec H.264 › Audio Codec AAC
3. 設定輸出路徑
4. Render › Render Animation（Ctrl + F12）
注意：如果 Sequencer 裡有片段，渲染時會輸出剪輯結果而不是 3D 場景；Post Processing 面板的 Sequencer、Compositing 勾選決定是否套用。
