# 物理模擬與粒子（Physics、Simulation）
<!-- 適用 Blender 4.x / 5.x -->

## 剛體模擬：物體掉落、碰撞（Rigid Body）
例如方塊掉到地上、骨牌倒下：
1. 選取會動的物件 › Object › Rigid Body › Add Active（或 Physics Properties › Rigid Body，Type: Active）
2. 選取地面 › Add Passive（固定不動但會被碰撞）
3. 按 Space 播放就會開始模擬
- Mass：質量；Friction：摩擦力；Bounciness：彈性
- Collisions › Shape：Convex Hull（凸包，快）、Mesh（照實際形狀，慢但準確，凹形物件用這個）
- 模擬前物件不要互相重疊，否則會炸開
- 一定要在第 1 格開始播放，模擬才會從頭計算
- 完成後 Object › Rigid Body › Bake to Keyframes 可以轉成關鍵影格

## 布料模擬（Cloth、桌布、旗子）
1. 新增平面並細分（Subdivide，面數要夠才會有皺褶）
2. Physics Properties › Cloth
3. 會被碰撞的物件（桌子、角色）加 Physics › Collision
4. 播放模擬
- 旗子固定一邊：先在編輯模式選取固定的點，建立頂點群組（Vertex Group），在 Cloth › Shape › Pin Group 選這個群組
- Quality Steps 越高越準確（穿模時調高）
- Self Collisions：布料自己碰撞自己（避免自己穿過自己）
- 布料穿過物體：Collision 的 Thickness Outer 調大、布料 Quality 調高、碰撞物件面數不要太低
- 模擬好想固定形狀：在修改器 Cloth 上 Apply（在想要的那一格）

## 快速特效（Quick Effects：煙、火、液體、爆炸）
Object › Quick Effects 可以一鍵建立：
- Quick Smoke：煙霧（Smoke）、火焰（Fire）或兩者
- Quick Liquid：液體
- Quick Explode：物件碎裂爆炸
- Quick Fur：毛髮
建立後會自動產生一個盒子（Domain），模擬只會在盒子範圍內發生。
煙和液體需要烘焙（Bake）才能流暢播放，Resolution Divisions 越高越細緻但越慢，初學從 32～64 開始。

## 流體模擬（Fluid、Domain、Flow、Effector）
Blender 的流體（Mantaflow）由三種角色組成：
- Domain：模擬範圍的盒子
- Flow：流體的來源（噴出煙、火、液體）
- Effector：障礙物（流體會繞過或被擋住）
Domain 的 Cache 設定資料夾後按 Bake Data（液體還要 Bake Mesh）。檔案很大、計算很久，建議先用低解析度測試。

## 毛髮（Hair Curves、Particle Hair）
- 新版毛髮系統：選取物件 › Shift + A › Curves › Empty Hair，切換到 Sculpt Mode 用毛髮筆刷「長」頭髮（Add、Comb 梳、Cut 剪、Density）
- 舊版粒子毛髮：Particle Properties › 按 + › Type 改 Hair，調整 Number（數量）、Hair Length（長度）
- 毛髮在 Cycles 渲染最好看，材質建議用 Principled Hair BSDF
頭髮數量很多時電腦會很慢，視窗中可以只顯示部分（Viewport Display Amount）。

## 粒子發射（Particle Emitter、下雪、火花）
Particle Properties › 按 + › Type: Emitter：
- Number：粒子數量；Frame Start / End：發射時間；Lifetime：存活時間
- Velocity › Normal：沿表面法線噴出的速度
- Render › Render As › Object：每個粒子顯示成指定的物件（雪花、落葉）
- Physics Properties 的 Field Weights › Gravity 設 0 可以關掉重力（漂浮效果）
用 Force Field（Shift + A › Force Field：Wind 風、Turbulence 亂流、Vortex 漩渦）影響粒子。

## 柔體（Soft Body、果凍效果）
Physics Properties › Soft Body，物件會像果凍一樣晃動變形，可以做 Q 彈的效果。調 Goal（維持原形的程度）、Edges 的 Bending 等參數。

## 模擬快取與烘焙（Cache、Bake）
- 模擬的結果會暫存在快取（Cache）中，從第 1 格播放才會正確計算
- Physics › Cache › Bake：把模擬計算好存起來，之後播放、渲染不用重算
- 修改設定後要按 Delete Bake（Free Bake）再重新烘焙
- 渲染動畫前一定要先烘焙，否則可能每次結果不同或閃爍
- 4.x 以後幾何節點也有 Simulation Zone 可以做自訂模擬
