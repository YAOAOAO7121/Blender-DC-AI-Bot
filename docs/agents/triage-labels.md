# Triage 標籤

這些技能用五個標準的 triage 角色溝通。這份檔案把角色對應到這個 repo 的 issue tracker 實際使用的標籤名稱。

| mattpocock/skills 的標籤 | 我們 tracker 的標籤 | 意思                         |
| ------------------------ | ------------------- | ---------------------------- |
| `needs-triage`           | `needs-triage`      | 維護者需要評估這個 issue     |
| `needs-info`             | `needs-info`        | 等回報者補充資訊             |
| `ready-for-agent`        | `ready-for-agent`   | 規格完整，可以交給 AFK agent |
| `ready-for-human`        | `ready-for-human`   | 需要人來實作                 |
| `wontfix`                | `wontfix`           | 不會處理                     |

技能提到某個角色時（例如「加上 AFK-ready 的 triage 標籤」），用上表對應的標籤名稱。

如果實際用的標籤名稱不同，改「我們 tracker 的標籤」那一欄即可。
