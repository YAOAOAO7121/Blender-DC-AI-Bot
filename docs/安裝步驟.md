# Blender 課程 AI 教學助理｜安裝步驟（給老師）

> 以 **Windows 10/11 + NVIDIA 顯卡** 為準。

## ⚡ 快速安裝（建議）

電腦上要先有 **Ollama**（https://ollama.com/download）；要用作業健檢的話也要有 **Blender**。其他都會自動處理。

**方法一：已經有程式資料夾**（例如助理用隨身碟帶過來、或用 GitHub 的 Code → Download ZIP 下載解壓縮）
→ 雙擊資料夾裡的 **`install.bat`**

**方法二：什麼都還沒有**
→ 開始選單搜尋 `cmd` 打開，貼上這一行按 Enter（程式會下載到「使用者資料夾\Blender-DC-AI-Bot」）：

```
powershell -ExecutionPolicy Bypass -c "[Net.ServicePointManager]::SecurityProtocol='Tls12'; iwr https://raw.githubusercontent.com/YAOAOAO7121/Blender-DC-AI-Bot/main/install.ps1 -UseBasicParsing -OutFile $env:TEMP\bot-install.ps1; & $env:TEMP\bot-install.ps1"
```

安裝程式會自己做完下面這些事，中途只會問你幾個問題：

| 自動完成 | 會問你的 |
|---|---|
| 沒有 Python、Git 就自動安裝 | 有沒有舊電腦帶來的 `.env`（有的話拖曳進視窗，就不用填 Token 和金鑰） |
| 下載程式、安裝套件（裝在獨立的 `.venv`，不影響電腦上其他 Python） | Discord Token、Gemini 金鑰（沒有舊 `.env` 才問，申請方式看下面第 4、6 步） |
| 讀顯卡記憶體 → 挑模型（**電腦上已經有的模型會列出來，選了就不用重新下載**）→ 確認 100% 放進顯卡 | 提問頻道、審核頻道的 ID（第 5 步） |
| 設定模型常駐顯卡（`OLLAMA_KEEP_ALIVE`） | 要不要開機自動啟動、要不要關掉睡眠 |
| 檢查 Token 是否有效、**Message Content Intent 有沒有開**、機器人看不看得到頻道、Gemini 金鑰與模型名稱 | |
| 建立 `啟動機器人.bat`（當掉會自動重開） | |

最後出現「安裝完成！」就可以啟動了；有黃色 `[注意]` 的照提示修正後，**再執行一次 `install.bat`**，做好的步驟會自動跳過。

> ⚠️ 同一個機器人只能在一台電腦上線，**舊電腦上的機器人記得先關掉**。
> 程式更新、換顯卡後想重挑模型，也是再執行一次 `install.bat` 就好。

# 手動安裝（安裝程式出問題時再用）

> 照順序做完，機器人就會在 Discord 上線。全部大約 40–60 分鐘，大部分時間是在等下載。
> 指令都是在「終端機」（開始選單搜尋 `PowerShell` 或 `cmd`）裡輸入。

---

## 開始前先確認

| 項目 | 說明 |
|---|---|
| 一台要一直開著的電腦 | 機器人跑在這台電腦上，電腦關機或睡眠 = 機器人下線。學生那邊不用裝任何東西 |
| NVIDIA 顯卡 | 跑本地模型用，顯卡記憶體越大，能用的模型越聰明 |
| 硬碟空間 | 至少 30GB（大模型本身就要 15–80GB） |
| Discord 伺服器的管理權限 | 要能邀請機器人、建頻道 |
| Google 帳號 | 申請 Gemini API 金鑰用 |

> ⚠️ **如果機器人原本在別台電腦跑（例如助理的筆電）**：同一個機器人帳號只能在一台電腦上線，請**先把舊電腦的機器人關掉**（關掉那個黑色視窗），不然兩台會同時回答同一題。

---

## 第 1 步：看顯卡記憶體

終端機輸入：

```
nvidia-smi
```

表格中間會看到類似 `0MiB / 24564MiB`，後面那個數字就是顯卡記憶體（24564MiB ≈ 24GB）。**記下來，第 7 步要用。**

> 出現「找不到指令」→ 先到 NVIDIA 官網更新顯卡驅動程式再試一次。

---

## 第 2 步：安裝需要的軟體

依序安裝下面四個（都是一般的安裝程式，一路「下一步」即可）：

1. **Python 3.10 以上** — https://www.python.org/downloads/
   - ★ 安裝第一個畫面**務必勾選「Add Python to PATH」** ★
2. **Git** — https://git-scm.com/download/win （選項全部用預設）
3. **Ollama**（跑本地模型的程式）— https://ollama.com/download
   - 裝好後右下角工作列會出現一隻羊駝圖示，代表它在背景執行
4. **Blender**（作業健檢功能才需要；不用這個功能可以跳過）— https://www.blender.org/download/
   - 裝在預設位置 `C:\Program Files\Blender Foundation\` 最省事，機器人會自己找到

全部裝完後，**關掉終端機重開一個**，輸入下面三行確認都有裝好（每行都應該顯示版本號）：

```
python --version
git --version
ollama --version
```

---

## 第 3 步：下載機器人程式

終端機輸入（會把程式下載到「使用者資料夾\Blender-DC-AI-Bot」）：

```
cd %USERPROFILE%
git clone https://github.com/YAOAOAO7121/Blender-DC-AI-Bot.git
cd Blender-DC-AI-Bot
python -m pip install -r requirements.txt
```

> 用 PowerShell 的話，第一行改成 `cd $HOME`。
> 最後一行在安裝套件，跑一兩分鐘是正常的。

---

## 第 4 步：Discord 機器人設定

### 情況 A：沿用已經建好的機器人（從舊電腦搬過來）→ 直接跳到第 6 步

請助理把舊電腦上的 **`.env` 檔案**用**隨身碟或私人雲端**給你，放進 `Blender-DC-AI-Bot` 資料夾。
> ⚠️ `.env` 裡有機器人的密碼（Token）和 API 金鑰，**不要用 Discord、Email 群組或任何公開的地方傳**。

想保留舊的提問紀錄的話，這幾個檔案也一起複製過來（沒有也可以，會自動重新建立）：
`questions_log.csv`、`feedback_log.csv`、`answer_index.json`、`review_index.json`、`image_notes.json`、`knowledge_待審核\`、`knowledge_已退回\`、`knowledge\網路整理\`

### 情況 B：建立一個全新的機器人

1. 到 https://discord.com/developers/applications → 右上 **New Application** → 取名（例如「Blender 助教」）→ Create
2. 左邊選 **Bot**：
   - 按 **Reset Token** → **Copy**，先貼到記事本（這就是 `DISCORD_TOKEN`，只會顯示一次）
   - 往下找到 **Privileged Gateway Intents**，★**打開「Message Content Intent」**★ → 按 Save Changes
     （沒開的話機器人看不到學生打的字，會完全沒反應）
3. 左邊選 **OAuth2 → URL Generator**：
   - Scopes 勾 **bot**
   - Bot Permissions 勾：
     `View Channels`、`Send Messages`、`Create Public Threads`、`Send Messages in Threads`、
     `Read Message History`、`Add Reactions`、`Attach Files`
   - 複製最下面產生的網址 → 貼到瀏覽器 → 選你的課程伺服器 → 授權

---

## 第 5 步：準備頻道並複製頻道 ID

1. 在 Discord 伺服器建立兩個頻道：
   - **提問頻道**（例如 `#blender-提問`）：學生在這裡發問，機器人會自動開討論串回答
   - **老師審核頻道**（例如 `#ai-審核`，建議設成只有老師/助教看得到）：AI 從網路整理的新筆記會先貼到這裡，老師按 ✅ 才會加進知識庫。**不想審核可以不建**
   - 審核頻道設成私人的話，記得在頻道權限裡**把機器人加進去**，不然它看不到
2. 打開開發者模式：Discord「使用者設定 → 進階 → 開發者模式」打開
3. 對頻道名稱按右鍵 → **複製頻道 ID**，分別記下來
4. （選填）只想讓特定人能審核：對自己的頭像按右鍵 → **複製使用者 ID**

---

## 第 6 步：申請 Gemini API 金鑰

機器人平常用本地模型回答，但這幾件事仍然要靠 Gemini：**看學生的截圖、把網路資料整理成筆記、本地模型答不出來時的備援**。

1. 到 https://aistudio.google.com/apikey 用 Google 帳號登入
2. 按 **Create API key** → 複製金鑰（`GEMINI_API_KEY`）

> 學生傳的截圖、網路查到的資料會送到 Google 處理。免費額度的使用條款與付費方案不同，正式上線前建議看一下 Google 目前的資料使用說明，再決定要不要綁定付款帳戶。

---

## 第 7 步：下載本地模型

依照第 1 步的顯卡記憶體選一個：

| 顯卡記憶體 | 建議模型 | 下載指令 | `LOCAL_CTX` |
|---|---|---|---|
| 4–8GB | Qwen 3 4B | `ollama pull qwen3:4b` | 4096 |
| 12–16GB | Qwen 3.5 9B | `ollama pull qwen3.5:9b` | 8192 |
| 24GB（RTX 3090/4090） | Qwen 3.6 27B | `ollama pull qwen3.6:27b` | 16384 |
| 32GB（RTX 5090） | Qwen 3.6 35B | `ollama pull qwen3.6:35b` | 16384 |
| 80GB 以上 | Qwen 3.5 122B | `ollama pull qwen3.5:122b` | 32768 |

> 模型名稱更新很快，下載前先到 https://ollama.com/library 搜尋 `qwen` 確認名稱還在。
> 建議用 Qwen 系列（中文好）；**不要用** `deepseek-r1`、`gemma4` 這類「會先思考」的模型，可能會把思考過程當成答案送給學生。

### 確認模型整個放得進顯卡

開兩個終端機：

```
ollama run qwen3.6:27b          ← 第一個視窗：隨便問一句話，等它回答
ollama ps                       ← 第二個視窗
```

`PROCESSOR` 欄顯示 **`100% GPU`** 才 OK。如果出現 `30%/70% CPU/GPU` 這種混合，代表放不下、會很慢，請換小一級的模型。問完在第一個視窗輸入 `/bye` 離開。

### 讓模型一直留在顯卡裡

Ollama 預設閒置 5 分鐘就會把模型卸載，大模型重新載入很慢，學生會等很久。

1. 開始選單搜尋「**編輯系統環境變數**」→ 環境變數
2. 「系統變數」→ 新增：變數名稱 `OLLAMA_KEEP_ALIVE`，值 `-1`
3. 右下角羊駝圖示按右鍵 → Quit Ollama，再從開始選單重新打開 Ollama

---

## 第 8 步：填寫設定檔 `.env`

在 `Blender-DC-AI-Bot` 資料夾裡：

- **情況 A**（已經有 `.env`）：用記事本打開，只改下面「本地模型」那幾行就好；如果檔案裡沒有 `FEEDBACK`、`REVIEW_CHANNEL_ID`、`BLEND_CHECK` 這些選項，從 `.env.example` 複製過來補上
- **情況 B**（新的）：把 `.env.example` 複製一份，改名成 **`.env`**（注意前面有個點、沒有 .txt），用記事本打開填入

```ini
DISCORD_TOKEN=第4步的Token
GEMINI_API_KEY=第6步的金鑰
ASK_CHANNEL_ID=提問頻道的ID

# 本地模型（照第 7 步的表）
LOCAL_MODEL=qwen3.6:27b
LOCAL_CTX=16384
USE_LOCAL=1
LOCAL_JUDGE=1
LOCAL_KEEP_RATIO=0.5        ← 大模型用 0.5；8GB 以下的小模型維持 0.7

# 老師審核頻道（不用就留空白）
REVIEW_CHANNEL_ID=審核頻道的ID
REVIEWER_IDS=老師的使用者ID     ← 空白 = 看得到審核頻道的人都能審

# 作業健檢（沒裝 Blender 就設 BLEND_CHECK=0）
BLEND_CHECK=1
BLENDER_PATH=                  ← Blender 裝在預設位置就留空白
```

> Windows 預設會隱藏副檔名，存檔時請確認檔名是 `.env` 不是 `.env.txt`（檔案總管「檢視 → 顯示 → 副檔名」打勾就看得到）。

## 第 9 步：測試

在 `Blender-DC-AI-Bot` 資料夾的終端機裡依序執行：

```
python tests/test_persona.py --local
```
→ 會用本地模型回答幾題內建問題，看語氣和速度。第一次會比較慢（載入模型）。

```
python knowledge.py 布林運算怎麼用
```
→ 會列出這題查到哪幾段課程資料、分到哪一章。

```
python homework_check.py 任一個作業.blend
```
→（有開作業健檢才需要）會印出健檢報告，並在資料夾裡產生 `健檢預覽.png`。

## 第 10 步：正式啟動

```
python bot.py
```

看到這些訊息就成功了：

```
[知識庫] 已載入 30 個檔案、xxx 段
本地模型就緒：qwen3.6:27b
語氣：小樽（persona/）
審核頻道：#ai-審核（網路筆記要老師按 ✅ 才入庫）
作業健檢：C:\Program Files\Blender Foundation\Blender 4.x\blender.exe
已上線：Blender 助教#1234
```

到提問頻道打一句「物件不見了怎麼辦」，機器人會開一個討論串回答。

> **這個黑色視窗不能關**，關掉機器人就下線。要停止機器人：在視窗裡按 `Ctrl + C`。

### （建議）做一個雙擊就能啟動的捷徑

在 `Blender-DC-AI-Bot` 資料夾裡新增一個文字檔，貼上下面內容，存成 **`啟動機器人.bat`**：

```bat
@echo off
cd /d "%~dp0"
:loop
python bot.py
echo 機器人停止了，10 秒後自動重新啟動（要完全關閉請直接關掉這個視窗）
timeout /t 10
goto loop
```

以後雙擊它就會啟動；萬一程式出錯停掉，也會自動重開。

想讓電腦**開機就自動啟動**：按 `Win + R` → 輸入 `shell:startup` → 把 `啟動機器人.bat` 的**捷徑**放進去。
另外記得到「設定 → 系統 → 電源」把**睡眠設成「永不」**。

## 上線後老師會用到的操作

| 想做的事 | 怎麼做 |
|---|---|
| 審核 AI 從網路整理的筆記 | 在審核頻道對那則訊息按 ✅（加進知識庫）或 ❌（退回） |
| 修改審核中的筆記 | **回覆**那則訊息打字 → 會加到筆記最後的「老師補充」；回覆並**上傳改好的 .md** → 整份取代。改完再按 ✅ |
| 看哪些題目被學生按 👎 | 審核頻道會自動通知，附討論串連結 |
| 新增／修改課程資料 | 編輯 `knowledge\` 裡的 .md 檔，存檔立刻生效，不用重開機器人。寫法看 `knowledge\_說明.md` |
| 調整回答語氣 | 編輯 `persona\小樽_完整.md`（Gemini 用）和 `persona\小樽_精簡.md`（本地模型用），存檔下一題就生效 |
| 看學生問了什麼 | 用 Excel 打開 `questions_log.csv`（含分類欄，可以篩選哪一章最多人問）。**看完記得關掉 Excel**，開著的時候機器人寫不進去 |
| 看學生按讚／倒讚紀錄 | `feedback_log.csv` |
| 測試期結束、不想顯示資料來源小字 | `.env` 設 `SHOW_SOURCES=0`，重開機器人 |

## 更新程式（助理改了新版之後）

關掉機器人 → 在資料夾的終端機輸入：

```
git pull
python -m pip install -r requirements.txt
```

再重新啟動。`.env`、紀錄檔和老師審核過的筆記都不會被覆蓋。

## 常見問題

| 狀況 | 原因與解法 |
|---|---|
| 啟動時出現「Discord Token 無效」／`LoginFailure: Improper token` | Token 貼錯（貼成 Application ID 或 Client Secret），或之後又按過 Reset Token 讓舊的失效。重新執行 `install.bat`，它會顯示目前 Token 的頭尾讓你核對，並讓你當場重貼 |
| 機器人在線上，但學生發問完全沒反應 | ① 沒開 **Message Content Intent**（第 4 步） ② `ASK_CHANNEL_ID` 填錯 ③ 機器人在那個頻道沒有權限 |
| 啟動時出現「⚠️ 找不到本地模型」 | Ollama 沒開（看右下角有沒有羊駝），或 `.env` 的 `LOCAL_MODEL` 跟 `ollama list` 顯示的名稱不一樣。這時會全部改用 Gemini，還是能回答 |
| 回答很慢、或一直顯示「Gemini（本地模型未啟用或失敗）」 | 模型太大放不進顯卡（重做第 7 步的 `ollama ps` 檢查），或沒設 `OLLAMA_KEEP_ALIVE` |
| 兩個機器人同時回答同一題 | 舊電腦上的機器人沒關 |
| 回答出現簡體字 | 套件沒裝完整，重跑 `python -m pip install -r requirements.txt` |
| 「⚠️ questions_log.csv 被其他程式開著」 | Excel 開著紀錄檔，關掉就好（那一筆會漏記，不影響回答） |
| 作業健檢說「找不到 Blender」 | Blender 不在預設位置 → `.env` 填 `BLENDER_PATH=C:\你的路徑\blender.exe` |
| 學生的 .blend 傳不上來 | Discord 免費伺服器單檔上限 10MB，請學生先用 File → Clean Up → Purge Unused Data 清掉沒用到的資料、縮小貼圖再傳，或直接找助教 |
| 審核頻道沒收到筆記 | 審核頻道是私人頻道但沒把機器人加進權限；或 `REVIEW_CHANNEL_ID` 填錯 |
| `python` 不是內部或外部命令 | 安裝 Python 時沒勾「Add Python to PATH」→ 重新執行安裝程式選 Modify 勾起來，或改用 `py` 代替 `python` |

更詳細的運作原理請看同資料夾的 `技術文件.md`。
